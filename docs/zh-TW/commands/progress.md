# 進度查詢

## 等級進度 / 牌子進度

查詢指定等級或版本牌子下的達成進度或成績統計，支援篩選和分頁。

**指令：** `/進度 <等級或牌子> [評價/評級] [篩選] [頁數]`

本指令有三種模式：等級加評價為**等級進度**，只填等級為**等級統計**，牌子字加評級為**牌子進度**。

### 等級進度模式

**參數：**

| 參數 | 說明 | 示例 |
|------|------|------|
| 等級 | `1`～`15`，可帶 `+` | `13+` |
| 評價 | 評價名、FC / 同步評價或 DX 星級 | `SSS`、`fc`、`5star` |
| 已完成/未完成/未開始 | 可選，篩選完成狀態 | `已完成`、`未完成`、`未開始` |
| 頁數 | 可選，預設第 1 頁 | `2` |

**分數評價對照：**

| 評價 | 達成率 |
|------|--------|
| `S` | ≥ 97.0000% |
| `S+` | ≥ 98.0000% |
| `SS` | ≥ 99.0000% |
| `SS+` | ≥ 99.5000% |
| `SSS` | ≥ 100.0000% |
| `SSS+` | = 101.0000% |

**同步/FC 評價：** `fc`、`fc+`、`ap`、`ap+`、`fs`、`fs+`、`fdx`、`fdx+`

**DX 星級評價：** `1star`～`7star`（如 `5star` 表示 DX 星級 ≥ 5 星；`7star` 為理論 DXScore 100%）

**示例：**

| 指令 |
|------|
| `/進度 13+ SSS` |
| `/進度 14 fc` |
| `/進度 14 5star` |
| `/進度 13+ SS 已完成` |
| `/進度 14 ap 未完成 2` |

::: tip 圖中包含
完成率環與難度 × 定數的完成率矩陣；未完成的譜面會標出離目標還差多少。
:::

### 等級統計模式

不填評價時，顯示該等級的成績統計。

**格式：** `/進度 <等級> [已遊玩/未遊玩] [頁數]`

統計包括遊玩覆蓋率與平均達成率，評級 / 連擊 / 同步 / DX 星分佈（未遊玩的譜面也計入），以及每個難度 × 定數的遊玩數與平均達成率。加上 `已遊玩` 或 `未遊玩` 可以翻頁查看對應的譜面。

**示例：**

| 指令 | 說明 |
|------|------|
| `/進度 13+` | 13+ 的成績統計 |
| `/進度 13+ 已遊玩` | 查看 13+ 已遊玩的譜面 |
| `/進度 13+ 未遊玩 2` | 查看 13+ 未遊玩的譜面，第 2 頁 |

### 版本牌子進度模式

查詢指定版本牌子的通關進度（如「丸將」「真極」等）。

**格式：** `/進度 <牌子字> <評級>`

| 評級 | 說明 |
|------|------|
| `極` | FC 所有曲目 |
| `將` | SSS 所有曲目 |
| `神` | AP 所有曲目 |
| `舞舞` | FDX 所有曲目 |

**示例：**

| 指令 |
|------|
| `/進度 丸 將` |
| `/進度 真 極` |
| `/進度 鏡 神 2` |

::: tip
牌子字和評級可以連寫，例如 `/進度 丸將` 與 `/進度 丸 將` 效果相同。
:::

## 分類進度

按歌曲分類（動漫、東方 Project 等）查詢進度或成績統計。

**指令：** `/分類進度 <分類> [評價] [篩選] [頁數]`

**參數：**

| 參數 | 說明 | 示例 |
|------|------|------|
| 分類 | 歌曲類別名稱 | `動漫`、`東方`、`舞萌`、`V家`、`遊戲`、`音擊`、`宴` |
| 評價 | 可選，評價名或 FC / 同步評價；不填時顯示該分類的成績統計（與[等級統計模式](#等級統計模式)相同） | `SSS`、`fc`、`ap` |
| 篩選 | 可選。填了評價時為 `已完成`、`未完成`、`未開始`；不填評價時為 `已遊玩`、`未遊玩` | `已完成` |
| 頁數 | 可選，預設第 1 頁 | `2` |

**示例：**

| 指令 |
|------|
| `/分類進度 動漫 SSS` |
| `/分類進度 東方 SS 2` |
| `/分類進度 舞萌 fc 已完成 2` |
| `/分類進度 動漫` |
| `/分類進度 宴 已遊玩` |

## 分數列表

查詢你在指定等級/定數下所有曲目的分數列表，支援多維篩選與排序。

**指令：** `/分數列表 [等級或定數] [篩選條件...] [排序] [頁數]`

**篩選條件（可疊加）：**

| 類型 | 可用值 |
|------|--------|
| Combo | `ap`、`ap+`/`app`、`fc`、`fc+`/`fcp`、`寸`（寸止） |
| Sync | `fs`、`fs+`/`fsp`、`fdx`、`fdx+`/`fdxp` |
| 評價 | `sss+`、`sss`、`ss+`、`ss`、`s+`、`s`、`a`、`aa`、`aaa`、`b`、`bb`、`bbb` 等 |
| 譜面類型 | `dx`、`sd` |
| 新舊版本 | `new`（新版）、`old`（舊版） |
| DX 星級 | `1star`～`7star`（`7star` = 理論 DXScore 100%） |
| 遊戲版本 | 牌子字（如 `雙`、`鏡`、`丸`）或版本英文別名（如 `buddies`、`prism`；DX 無印用 `deluxe`）；Plus 版本用 `+` 結尾，如 `buddies+` |

**運算子（僅 Combo / Sync / 評價可用）：**

| 寫法 | 含義 |
|------|------|
| 直接寫（如 `fc`、`sss`） | Combo / Sync 向上包含（`fc` 含 FC+、AP 等）；評價為精確匹配（`sss` 僅 SSS，不含 SSS+） |
| `=`（如 `=fc`） | 精確匹配，如 `=fc` 僅顯示恰好 FC、未達到 FC+ 的曲目 |
| `>=` 或 `以上`（如 `>=s`、`s以上`） | 向上包含，如 `>=s` 顯示 S 及以上的曲目 |

參數輸入有誤時，Bot 會指出是哪一個參數，並提示可能想輸入的寫法。結果圖會標出本次的查詢條件，並統計篩選結果的評級、連擊、同步與 DX 星分佈。

**排序：** `按X`（預設降序），或 `按X+`（升序）/ `按X-`（降序）

可排序欄位：`ra`（Rating 貢獻）、`達成度`/`acc`、`dx`（DX 分）、`定數`/`ds`

**示例：**

| 指令 | 說明 |
|------|------|
| `/分數列表 13+` | 查詢所有 13+ 曲目分數 |
| `/分數列表 14 fc` | 篩選 FC（含 FC+）及以上 |
| `/分數列表 14 =fc` | 僅顯示恰好 FC（未達 FC+）的曲目 |
| `/分數列表 14 ap 2` | 篩選 AP 及以上，第 2 頁 |
| `/分數列表 14 dx sss` | 同時篩選 DX 譜和 SSS（不含 SSS+） |
| `/分數列表 14 dx >=sss` | 同時篩選 DX 譜和 SSS 及以上 |
| `/分數列表 s以上` | 篩選所有 S 及以上的成績 |
| `/分數列表 14 按ra-` | 按 Rating 貢獻降序排列 |
| `/分數列表 14 1star` | 篩選 DX 星級為 1 星的曲目 |
| `/分數列表 雙` | 篩選 BUDDiES 版本曲目 |
| `/分數列表 buddies+` | 篩選 BUDDiES PLUS 版本曲目 |
