# 成績查詢

## 曲目個人遊玩資料

查詢指定曲目的個人遊玩詳情，包括達成率、DX 分、FC/FS 狀態等。

**指令：** `/info <曲目ID或曲名>`

**參數：**

| 參數 | 說明 |
|------|------|
| 曲目ID或曲名 | 數字 ID 或歌曲名稱/別名 |

支援查詢他人資料，在指令後加 `#使用者名稱`。

**示例：**

| 指令 |
|------|
| `/info 11451` |
| `/info 潘多拉` |
| `/info 11451 #Sakura` |

::: tip 圖中包含
- **我的成績**：同一帳號在多個區服都有成績時，各區服會並排展示，方便橫向對比；某難度在該區服沒有對應譜面時顯示「無此難度」。
- **好友對比**：加 `#使用者名稱` 查詢他人時，對方成績會與自己主區服的成績逐難度對比，標出達成率差值（▲/▼）；對方隱藏了查詢權限時只顯示「私密」。
:::

## 分數線容錯

查詢指定難度下每種 Note 的扣分值、DX 星級所需 DX 分數的容錯範圍，以及各評級的 TAP 失誤容錯。

**指令：** `/分數線 <歌曲ID> [難度顏色]`

**參數：**

| 參數 | 說明 | 預設值 |
|------|------|--------|
| 歌曲ID | 數字 ID | — |
| 難度顏色 | `綠`、`黃`、`紅`、`紫`、`白` | 紫 |

**示例：**

| 指令 |
|------|
| `/分數線 11451` |
| `/分數線 11820 白` |

::: tip 圖中包含
- **DX 星級**：達成各 DX 星級所需的 DX 分數容錯範圍。
- **評級容錯**：以理論值 101% 為基準，達成 SSS+ / SSS / SS+ / SS / S+ / S 各評級時，全程僅 TAP 粉 / TAP 綠 / TAP Miss 單一失誤的最大可容許個數（三檔互斥）。
:::

## 識分（成績圖分析）

發送一張成績圖，自動辨識達成率與 Note 判定分佈，並**反推 BREAK 的細分構成**（絕贊 / 50 落 / 100 落等）與逐 Note 的失分明細。

**指令：** `/識分`

**用法：**

- 發送指令時**同時附帶**一張成績圖；
- 或**引用**一條含成績圖的訊息，再 @ Bot 並發送指令。

**結果圖包含：**

- 匹配到的曲目、難度與 DX 星級、連擊評價（FC / FC+ / AP / AP+）
- 判定分佈 & 失分表：每格顯示「數量／合計扣分／單個扣分」
- 反推出的 BREAK 細分；若存在多組數學上等價的解，會一併列出

### 手動修正模式

當圖片壓縮過度、部分數字辨識錯誤時，可以不帶圖片、直接用參數呼叫，手動給出正確數值。

**指令：** `/識分 id=<歌曲ID> ach=<達成率> tap=<CP/P/GR/GD/MS> hold=... slide=... touch=... break=...`

**參數：**

| 參數 | 說明 | 是否必填 |
|------|------|----------|
| `id` | 歌曲 ID（數字） | 與 Note 分佈至少填其一 |
| `ach` | 達成率，範圍 0～101，如 `100.8623` | 必填 |
| `tap` / `hold` / `slide` / `break` | 各類型的 5 檔判定數，按 `CP/P/GR/GD/MS` 順序用 `/` 分隔 | 必填 |
| `touch` | 同上；該譜面無 TOUCH 時可省略（按全 0 處理） | 可選 |

參數名固定為英文（`ach` 也可寫作 `acc`），順序不限。

**示例：**

```
/識分 id=834 ach=100.8623 tap=380/0/0/0/0 hold=52/0/0/0/0 slide=90/0/0/0/0 touch=0/0/0/0/0 break=47/0/1/0/0
```

::: tip 提高辨識成功率
- 盡量發送**原圖**，並確保遊戲畫面**頂部的 Note 分佈**清晰完整。
- 辨識失敗時，Bot 會回覆帶有已辨識數值的指令範本，複製後改正錯誤的數字重新發送即可；在 Discord 上則可直接點擊「✏️ 修正參數」按鈕填寫。
:::

::: warning 限制
- 暫不支援宴譜（UTAGE）成績推算。
- 若同一組 Note 分佈在曲庫中對應多首曲目，需要用 `id=` 指定具體譜面。
:::

## 譜面統計

查詢指定曲目各難度的 AP 率、FC 率、遊玩率等統計資料。

**指令：** `/譜面統計 <曲目ID或曲名> [區服]`

**參數：**

| 參數 | 說明 | 可選值 |
|------|------|--------|
| 曲目ID或曲名 | 數字 ID 或歌曲名稱/別名 | — |
| 區服 | 篩選區服（可選） | `cn`、`jp`、`intl` |

**示例：**

| 指令 |
|------|
| `/譜面統計 11451` |
| `/譜面統計 潘多拉` |
| `/譜面統計 11451 jp` |
| `/譜面統計 11451 cn` |

## 最近遊玩

按局查看你的遊玩記錄，每頁一局（一次遊戲中打的全部曲目），第 1 頁為最近一局。

::: info 僅日服 / 國際服
此功能僅日服（JP）和國際服（INTL）用戶可用。
:::

**指令：** `/最近遊玩 [頁數]`

支援透過 `#使用者名稱` 查詢他人資料（需對方允許分數查詢）。

**示例：**

| 指令 | 說明 |
|------|------|
| `/最近遊玩` | 查看最近一局 |
| `/最近遊玩 2` | 查看上一局，數字越大越早 |
| `/最近遊玩 #Sakura` | 查看 Sakura 最近一局 |

::: tip 圖中包含
每首曲目的達成率、評價與判定明細，並像 [`/識分`](#識分-成績圖分析) 一樣推算 BREAK 的細分檔與每格失分。機廳名稱只在本人私訊查詢時顯示。
:::

::: warning 記錄從第一次更新記錄起保存
maimai NET 只保留最近 50 首的遊玩記錄。McMai 在每次 `/更新記錄` 時保存這些記錄，所以第一次更新之前的遊玩不會出現。兩次更新之間打了超過 50 首時，較早的記錄會被 NET 覆蓋，Bot 會提醒你在打滿 50 首之前更新。
:::

## Rating 變化

查看 Rating 曲線、每日上分與每一次上分的記錄。

::: info 僅日服 / 國際服
此功能僅日服（JP）和國際服（INTL）用戶可用，資料來自[最近遊玩](#最近遊玩)的記錄。
:::

**指令：** `/rating記錄 [範圍] [頁數]`

**參數：**

| 參數 | 說明 | 示例 |
|------|------|------|
| 範圍 | 可選，預設為本版本（大版本上線日起）。`30d` 或 `30天` 為近若干天，`all` 或 `全部` 為全部記錄 | `30d` |
| 頁數 | 可選，第 1 頁為最近的上分記錄 | `2` |

範圍與頁數不分先後。支援透過 `#使用者名稱` 查詢他人資料（需對方允許分數查詢）。

**示例：**

| 指令 | 說明 |
|------|------|
| `/rating記錄` | 本版本的 Rating 變化 |
| `/rating記錄 30d` | 近 30 天 |
| `/rating記錄 all` | 全部記錄 |
| `/rating記錄 30d 2` | 近 30 天，上分記錄第 2 頁 |

::: tip
大版本切換、定數調整等非遊玩造成的 Rating 變化會另外註明；記錄不連續的區段以虛線表示。
:::
