# 帳號與伺服器

## 綁定 SEGA ID

將你的 QQ 帳號與 SEGA ID 關聯，用於查詢 maimai NET 資料。

只有國際服和日服用戶需要綁定帳號，國服用戶透過 MAID 直接更新資料。

**指令：** `/綁定`

**說明：** 執行後會生成一個專屬綁定連結（或 QR Code），在瀏覽器中開啟並完成授權即可。

::: warning 注意
每次執行 `/綁定` 會生成新的驗證碼，請及時完成綁定。
:::

---

## 用書籤更新成績

不輸入 SEGA ID 和密碼也能更新成績。安裝一個書籤，在已經登入的 maimai NET 頁面上點一下，成績就會上傳到 McMai。

適用於**日服和國際服**。國服使用者透過 MAID 更新，不需要書籤。

::: tip 為什麼不用交密碼
抓取過程跑在你自己的瀏覽器裡，用的是你已經登入好的工作階段，全程不需要把 SEGA ID 和密碼交給 Bot。
:::

**開始使用：** 在聊天中傳送 `/綁定` 取得連結，開啟後點擊頁面底部的「不想輸入帳號密碼？用書籤更新成績」。

綁定頁網址：[id.moev.cc](https://id.moev.cc)（產生書籤需要 Bot 發給你的驗證碼）

### 大致流程

| 步驟 | 說明 |
|------|------|
| 1. 產生書籤 | 在綁定頁填入驗證碼，產生屬於你的專屬書籤 |
| 2. 裝進瀏覽器 | 電腦端拖到書籤列；手機端複製程式碼後新建書籤 |
| 3. 登入 maimai NET | 用**系統瀏覽器**開啟日服或國際服並登入 |
| 4. 點一下書籤 | 在 maimai NET 的任一頁面點擊即可，抓取約十幾秒 |

頁面上依「電腦 / iPhone / Android」分別給出了詳細的安裝步驟，跟著做即可。

::: warning 注意事項
- 書籤**每人獨一份**。重新產生會讓舊的立刻失效，所有裝過的裝置都要重裝一遍。
- 不要把程式碼貼到網址列，Chrome 會自動刪掉開頭的 `javascript:`，貼過去是壞的。
- SNS App 內建的瀏覽器無法執行書籤，請改用系統瀏覽器。
- iPhone 需要從**書籤列表**開啟；Android 需要在網址列輸入書籤名稱後點**書籤建議項**。兩者恰好相反。
- 驗證碼只能使用一次。之後想再查看或重新產生書籤，需要重新傳送 `/綁定`。
:::

## 多平台資料互通

同一個遊戲帳號（同一張卡）在不同平台綁定後，資料自動互通：**只需在任一平台更新一次成績，其餘平台同步可見**，不必在每個平台各更新一遍。

::: tip 提示
互通的判定單位是遊戲帳號，不是平台身分。綁定不同卡片的帳號會各自獨立，不會互通。
:::

## 解綁帳號

解除目前的 SEGA 帳號綁定，並清除你在**所有區服**的成績記錄。

**指令：** `/解綁帳號 [確認]`

::: danger 無法復原
解綁會一次性清除以下內容，且**無法復原**：

- SEGA 帳號綁定資訊（segaid、密碼）
- 你在所有區服（國服 / 日服 / 國際服）的成績記錄

為防止誤操作，需二次確認：先傳送 `/解綁帳號` 查看將刪除的內容，再傳送 `/解綁帳號 確認` 執行。確認請求 **5 分鐘** 內有效，逾時需重新發起。
:::

**示例：**

| 指令 | 說明 |
|------|------|
| `/解綁帳號` | 查看將刪除的內容並發起解綁請求 |
| `/解綁帳號 確認` | 確認並執行解綁（5 分鐘內有效） |

## 切換 Aime 卡片

查看或切換日服帳號下的 Aime 卡片槽位。

::: info 僅日服
此功能僅日服（JP）用戶可用，且需已綁定日服帳號。
:::

**指令：** `/aime [卡片序號]`

**別名：** `卡片`、`切卡`

**說明：**

- `/aime`：列出目前帳號下的所有 Aime 卡片，標註目前選中的卡片、Rating 與卡片類型（標準卡 / 免費卡）。
- `/aime <序號>`：切換到指定序號的卡片。
- 若帳號下只有一張卡片，則無需切換。

切換後將在下次執行 `/更新記錄` 時生效。

**示例：**

| 指令 | 說明 |
|------|------|
| `/aime` | 查看帳號下所有 Aime 卡片 |
| `/aime 2` | 切換到第 2 張卡片 |

## 設定使用者名稱

設定一個便於他人透過 `#使用者名稱` 查詢你資料的標識符。

**指令：** `/使用者名稱 [名稱|QQ號|清除|clearqq]`

**示例：**

| 指令 | 說明 |
|------|------|
| `/使用者名稱 Sakura` | 設定使用者名稱為 Sakura |
| `/使用者名稱` | 查看目前使用者名稱、查分器 ID 與綁定 QQ |
| `/使用者名稱 清除` | 清除使用者名稱 |
| `/使用者名稱 123456789` | 綁定 QQ 號（5～11 位數字） |
| `/使用者名稱 clearqq` | 解綁已綁定的 QQ 號 |

**查詢標識符說明：**

每位用戶都有一個系統自動分配的**查分器 ID**（`#mc` 開頭的短 ID），即使未設定使用者名稱也可使用它被他人查詢。設定使用者名稱後，他人可以透過 `#使用者名稱` 查詢你，也可以繼續使用查分器 ID。

::: warning 注意
在使用使用者名稱作為查詢參數時，使用者名稱前一定要加 `#`。

例如 `/b50 #Sakura`，而不是 `/b50 Sakura`。
:::

::: tip 審核機制
使用者名稱設定後需經過審核：

- **審核中**：可以用 `#使用者名稱` 被他人查詢，但顯示時使用者名稱會被部分遮蓋
- **審核通過**：使用者名稱完整顯示
- **審核不通過**：使用者名稱將被自動刪除，需重新設定

使用者名稱每 **3 天** 只能修改一次，請謹慎設定。
:::

## 隱私設定

控制他人能否查詢你的遊戲資料。

**指令：** `/隱私設定 <動作> [目標]`

**動作：**

| 動作 | 說明 |
|------|------|
| `查看` | 查看目前隱私設定 |
| `開啟` | 允許他人查詢指定目標 |
| `關閉` | 禁止他人查詢指定目標 |
| `重置` | 恢復指定目標為預設（全部允許） |

**目標：**

| 目標 | 說明 |
|------|------|
| `查詢` | 總開關，控制所有查詢權限 |
| `b50查詢` | Best 50 等各類 50 查詢 |
| `分數查詢` | 成績（info）查詢 |
| `進度查詢` | 完成表 / 進度表查詢 |

::: tip
關閉 `查詢`（總開關）後，他人將無法查詢你的任何資料，優先權高於其他單項設定。
:::

**示例：**

| 指令 | 說明 |
|------|------|
| `/隱私設定 查看` | 查看目前各項隱私狀態 |
| `/隱私設定 關閉 查詢` | 禁止他人查詢你的所有資料 |
| `/隱私設定 關閉 分數查詢` | 單獨禁止他人查詢你的成績 |
| `/隱私設定 開啟 b50查詢` | 重新允許他人查詢你的 Best 50 |
| `/隱私設定 重置 查詢` | 恢復所有查詢權限為預設值 |

## 好友管理

管理你的 McMai 好友清單，好友清單用於 PK 功能。

**指令：** `/好友 [動作] [參數]`

**別名：** `好友管理`

**動作：**

| 動作 | 說明 | 參數 |
|------|------|------|
| `列表` | 查看好友清單 | — |
| `新增` | 新增好友 | `#使用者名稱` |
| `刪除` | 刪除好友 | `#使用者名稱` 或槽位號 |

**示例：**

| 指令 | 說明 |
|------|------|
| `/好友 列表` | 查看好友清單 |
| `/好友 新增 #Sakura` | 新增名為 Sakura 的好友 |
| `/好友 新增 #Sakura 1` | 在槽位號為 1 的位置覆蓋新增名為 Sakura 的好友 |
| `/好友 刪除 1` | 刪除槽位號為 1 的好友 |
