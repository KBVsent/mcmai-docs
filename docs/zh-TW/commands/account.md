# 帳號與伺服器

## 綁定帳號

**指令：** `/綁定`

**說明：** 執行後會生成一個專屬綁定連結，在瀏覽器中開啟，選擇區服後依頁面提示完成綁定。綁定 SEGA ID 或授權落雪查分器後會立即更新一次成績，並可勾選同時將 McMai 的目前區服切換過去。

綁定連結只會傳送到僅你本人可見的地方：私訊、QQ 群組中僅你可點擊的按鈕、Discord `/bind` 斜線指令的私密回覆。其他群組情境下，Bot 會提示你私訊傳送 `/綁定`。

| 區服 | 方式 |
|------|------|
| 日本區 | 綁定 SEGA ID，或使用[書籤](/zh-TW/guide/bookmarklet-update)更新 |
| 國際區 | 綁定 SEGA ID，提交[登入權杖](#intl-token)，或使用[書籤](/zh-TW/guide/bookmarklet-update)更新 |
| 大陸區 | 開通 [NET 微信授權](/zh-TW/guide/cn-net-update)，[發送 MAID](#maid)，或授權[落雪查分器](#lxns) |

三個區服還可以透過[自訂資料來源](/zh-TW/guide/custom-data-source)上傳成績檔案。

::: warning 注意
綁定連結 10 分鐘內有效，每次執行 `/綁定` 都會生成新的連結。請勿分享給他人。
:::

::: tip 管理已關聯的帳號
綁定頁會列出各區服已關聯的遊戲帳號，點選即可切換目前使用的帳號（效果同 [`/選卡`](#aime)）。不再需要某個帳號時，可在綁定頁單獨解綁：解除關聯後成績資料保留，之後用同一帳號再次更新即可重新關聯。解綁以帳號密碼或落雪查分器更新的帳號時，已儲存的帳號密碼或落雪授權可能一併刪除，確認框會列出具體影響。
:::

## 國際區登入權杖 {#intl-token}

用 X、Facebook 或 LINE 登入 maimai DX NET、沒有 SEGA ID 密碼的國際區玩家，可以改用登入權杖綁定，之後同樣使用 `/更新記錄`。

傳送 `/綁定`，在綁定頁選擇「國際區」→「權杖」，貼上含 `clal` 的 cookie。取得方法可點擊輸入框旁的「問 ChatGPT 如何取得」，依自己的裝置詢問。

::: warning 權杖會因登出而失效
在任何裝置上登出 maimai DX NET，都會讓權杖失效，需要重新提交。權杖等同登入憑證，不要傳給他人。
:::

## 用書籤更新成績

日本區與國際區可透過瀏覽器已登入的 NET 工作階段更新成績，無需向 McMai 提交 SEGA ID 與密碼。

傳送 `/綁定`，在綁定頁選擇區服與「書籤」方式，產生並安裝書籤。安裝後在已登入的 maimai NET 頁面執行。

完整圖解見[書籤更新教學](/zh-TW/guide/bookmarklet-update)，包含電腦 Chrome、iPhone Safari 與 Android Chrome 的安裝與使用步驟。

書籤程式碼包含帳號上傳憑證，重新產生後舊程式碼立即失效。

## 大陸區 MAID 更新 {#maid}

私訊 Bot 或在群組內 @Bot 發送 MAID（`SGWCMAID` 開頭的 84 位字串），也可以在綁定頁「大陸區」→「MAID」中貼上，即可更新大陸區成績。大陸區 [PC50](/zh-TW/commands/b50#pc50) 所需的遊玩次數只隨 MAID 更新取得。

::: details 如何取得 MAID？
1. 進入「舞萌 | 中二」公眾號
2. 點擊「獲取二維碼」
3. 開啟 QR Code 頁面
4. 長按掃描，複製出現的 `SGWCMAID` 開頭字串
:::

## 落雪查分器 {#lxns}

大陸區玩家可以授權落雪查分器，以落雪上的成績使用 B50 等查詢功能。傳送 `/綁定`，在綁定頁選擇「大陸區」→「落雪」，點擊「前往落雪查分器授權」完成授權。

- 查詢自己的成績時會自動同步落雪上的新成績，也可以傳送 `/更新記錄` 立即同步。
- 落雪帳號與大陸區的其他帳號列在一起，用 [`/選卡`](#aime) 或在綁定頁切換。
- 落雪的資料不含遊玩記錄和遊玩次數，無法使用 `/最近遊玩`、`/rating記錄` 與 `/pc50`。
- 落雪的資料預設不計入排行榜，群排行與群 Rating 排行加上 [`all` 參數](/zh-TW/commands/leaderboard#群組內單曲排行)可一併查看。

授權失效時，Bot 會提示傳送 `/綁定` 重新授權，已同步的成績保留。

## 多平台資料互通

同一個遊戲帳號（同一張卡）在不同平台綁定後，資料自動互通：**只需在任一平台更新一次成績，其餘平台同步可見**，不必在每個平台各更新一遍。

::: tip 提示
互通的判定單位是遊戲帳號，不是平台身分。綁定不同卡片的帳號會各自獨立，不會互通。
:::

## 查成績時自動更新 {#auto-update}

查詢自己的成績時，如果資料超過 1 小時未更新，Bot 會先更新再顯示結果。落雪查分器不受 1 小時限制，查詢時有新成績就會同步。

**指令：** `/自動更新 [開|關]`

- 不帶參數：查看目前狀態。預設開啟。
- 適用於綁定了 SEGA 帳號（日本區、國際區）、國際區登入權杖或落雪查分器的資料。書籤、大陸區 NET 與 MAID、自訂資料來源的資料需要按原方式手動更新。
- 只在查詢自己時觸發，查詢他人不會更新對方的資料。查歌與今日運勢不會觸發。
- 日本區、國際區查看 `/最近遊玩` 與 `/rating記錄` 時同樣會自動更新。

**示例：**

| 指令 | 說明 |
|------|------|
| `/自動更新` | 查看目前狀態 |
| `/自動更新 關` | 關閉，之後需要時用 `/更新記錄` 手動更新 |
| `/自動更新 開` | 重新開啟 |

::: warning 更新期間請勿登入 NET
透過 SEGA 帳號或登入權杖更新（包括自動更新）時，排隊與更新期間請勿手動登入 maimai DX NET。更新完成後最近遊玩記錄會在背景繼續取得，接下來幾分鐘內同樣請勿登入。
:::

## 註銷帳號

清除你的全部登入憑證與成績記錄。

**指令：** `/註銷帳號 [確認]`

::: danger 無法復原
註銷會一次性清除以下內容，且**無法復原**：

- SEGA 帳號登入憑證（SEGA ID、密碼或登入權杖）
- 落雪查分器授權、自訂資料來源的上傳權杖
- 你在所有區服的成績記錄

為防止誤操作，需二次確認：先傳送 `/註銷帳號` 查看將刪除的內容，再傳送 `/註銷帳號 確認` 執行。確認請求 **5 分鐘** 內有效，逾時需重新發起。有成績更新正在進行時無法註銷，請等更新完成後再傳送。
:::

只想移除某一個遊戲帳號、保留其他資料時，請在綁定頁單獨解綁該帳號，見[管理已關聯的帳號](#綁定帳號)。

**示例：**

| 指令 | 說明 |
|------|------|
| `/註銷帳號` | 查看將刪除的內容並發起註銷請求 |
| `/註銷帳號 確認` | 確認並執行註銷（5 分鐘內有效） |

## 選卡 {#aime}

在目前區服已關聯的遊戲帳號之間切換。用不同方式更新過的資料（如大陸區的 NET 與 MAID、落雪查分器、自訂資料來源）各是一個帳號，互不覆蓋，查詢時使用目前選中的帳號。

**指令：** `/選卡 [序號]`

**別名：** `切換帳號`、`aime`、`卡片`、`切卡`

**說明：**

- `/選卡`：列出目前區服下的帳號，標註目前帳號、Rating、更新方式與最近更新時間。
- `/選卡 <序號>`：切換到指定帳號。
- 日本區綁定了 SEGA ID 時，清單還會附上該 SEGA ID 下尚未更新過的 Aime 卡片。選中這類卡片後，下次 `/更新記錄` 會更新這張卡，完成後自動切換到它。

用某種方式更新成績後，會自動切換到該方式對應的帳號。也可以在綁定頁的帳號清單中點選切換。

**示例：**

| 指令 | 說明 |
|------|------|
| `/選卡` | 查看目前區服的帳號清單 |
| `/選卡 2` | 切換到第 2 個帳號 |

## 設定使用者名稱

設定一個便於他人透過 `#使用者名稱` 查詢你資料的標識符。

**指令：** `/使用者名稱 [名稱|清除]`

**示例：**

| 指令 | 說明 |
|------|------|
| `/使用者名稱 Sakura` | 設定使用者名稱為 Sakura |
| `/使用者名稱` | 查看目前使用者名稱（未設定時顯示查分器 ID） |
| `/使用者名稱 清除` | 清除使用者名稱 |

**使用者名稱規則：** 可使用漢字、平假名、片假名、英文字母和數字，不能為純數字，最多 10 個字元。輸入的半形片假名、全形英數字會自動轉換；與他人使用者名稱形近難辨的名稱無法設定。

**查詢標識符說明：**

每位用戶都有一個系統自動分配的**查分器 ID**（`#mc` 開頭的短 ID），即使未設定使用者名稱也可使用它被他人查詢。設定使用者名稱後，他人可以透過 `#使用者名稱` 查詢你，也可以繼續使用查分器 ID。

::: warning 注意
在使用使用者名稱作為查詢參數時，使用者名稱前一定要加 `#`。

例如 `/b50 #Sakura`，而不是 `/b50 Sakura`。
:::

::: tip 審核機制
使用者名稱設定後需經過審核：

- **審核中**：可以用 `#使用者名稱` 被他人查詢，但顯示時使用者名稱會被部分遮蓋
- **審核通過**：使用者名稱完整顯示
- **審核不通過**：使用者名稱將被自動刪除，需重新設定

使用者名稱每 **3 天** 只能修改一次，請謹慎設定。
:::

## 隱私設定

控制他人能否查詢你的遊戲資料。

**指令：** `/隱私設定 <動作> [目標]`

**動作：**

| 動作 | 說明 |
|------|------|
| `查看` | 查看目前隱私設定 |
| `開啟` | 允許他人查詢指定目標 |
| `關閉` | 禁止他人查詢指定目標 |
| `重置` | 將所有查詢權限恢復為預設（全部允許），無需目標 |

**目標：**

| 目標 | 說明 |
|------|------|
| `查詢` | 總開關，控制所有查詢權限 |
| `b50查詢` | Best 50 等各類 50 查詢，以及 PK、上分查詢 |
| `分數查詢` | 成績（info）、最近遊玩、Rating 變化查詢 |
| `進度查詢` | 完成表、進度、分類進度、分數列表查詢 |

::: tip
關閉 `查詢`（總開關）後，他人將無法查詢你的任何資料，優先權高於其他單項設定。排行榜不受隱私設定影響。
:::

**示例：**

| 指令 | 說明 |
|------|------|
| `/隱私設定 查看` | 查看目前各項隱私狀態 |
| `/隱私設定 關閉 查詢` | 禁止他人查詢你的所有資料 |
| `/隱私設定 關閉 分數查詢` | 單獨禁止他人查詢你的成績 |
| `/隱私設定 開啟 b50查詢` | 重新允許他人查詢你的 Best 50 |
| `/隱私設定 重置` | 恢復所有查詢權限為預設值 |

## 好友管理

管理你的 McMai 好友清單，好友清單用於 PK 功能。

**指令：** `/好友 [動作] [參數]`

**別名：** `好友管理`

**動作：**

| 動作 | 說明 | 參數 |
|------|------|------|
| `列表` | 查看好友清單 | — |
| `新增` | 新增好友 | `#使用者名稱` 或 `#查分器ID`，可再加槽位號（1～3）覆蓋該槽位 |
| `刪除` | 刪除好友 | 槽位號（1～3） |

**示例：**

| 指令 | 說明 |
|------|------|
| `/好友 列表` | 查看好友清單 |
| `/好友 新增 #Sakura` | 新增名為 Sakura 的好友 |
| `/好友 新增 #Sakura 1` | 在槽位號為 1 的位置覆蓋新增名為 Sakura 的好友 |
| `/好友 刪除 1` | 刪除槽位號為 1 的好友 |
