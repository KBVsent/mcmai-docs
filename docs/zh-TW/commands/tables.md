# 定數與表格

## 定數表

查詢指定等級或定數的曲目定數表（圖片形式）。

**指令：** `/定數表 <等級或定數> [伺服器]`

**參數：**

| 參數 | 說明 | 示例 |
|------|------|------|
| 等級或定數 | 等級（如 `13`、`14+`）或定數範圍 | `13+`、`14.0` |
| 伺服器 | 查詢區服（可選） | `cn`、`jp`、`intl` |

**示例：**

| 指令 |
|------|
| `/定數表 13+` |
| `/定數表 14` |
| `/定數表 14 jp` |

---

## 段位表

查詢指定段位的課題曲目，並標註你在各曲目上的成績。僅可查詢自己。

**指令：** `/段位表 <段位名稱> [伺服器] [版本]`

**參數：**

| 參數 | 說明 |
|------|------|
| 段位名稱 | 如 `真初段`、`真十段`、`真皆伝` 等 |
| 伺服器 | 可選，`cn`、`jp`、`intl`（或 `中國服`、`日服`、`國際服`），用於查看其他區服的段位表 |
| 版本 | 可選，查看往期版本的段位，預設為目前版本。可填牌子字（如 `鏡`、`丸`）或英文版本名（如 `prism`、`circle+`） |

伺服器與版本不分先後。

**示例：**

| 指令 | 說明 |
|------|------|
| `/段位表 真十段` | 目前版本的真十段 |
| `/段位表 真皆伝 jp` | 日服目前版本的真皆伝 |
| `/段位表 真八段 jp 丸` | 日服 CiRCLE 版本的真八段 |

::: tip 可查詢的版本
- **日服 / 國際服**：SPLASH PLUS（煌）及之後的版本。
- **中國服**：舞萌DX 2023 及之後的版本，課題曲目為中國服實際曲目，與日服同名版本不同。

輸入的版本無法使用時，Bot 會列出該區服可選的版本。
:::

::: tip 跨區服查表
伺服器參數只決定查看哪個區服的段位，成績一律來自你透過 `/切換伺服器` 選定的區服。該區服有、而你所在區服尚未實裝的譜面會標為「未實裝」，與未遊玩區分開來。
:::

## 完成表

查詢牌子／等級評價的完成進度表。

**指令：** `/完成表 <等級評價或牌子> [牌子評級] [伺服器] [#使用者名稱]`

**參數：**

| 參數 | 說明 | 示例 |
|------|------|------|
| 等級評價或牌子 | 數字等級（如 `13`、`14+`）或版本牌子字（如 `真`、`丸`） | `13+` |
| 牌子評級 | 牌子模式必填（`極`、`將`、`神`、`舞舞`） | `將` |
| 伺服器 | 可選，查看其他區服的完成表（`cn`、`jp`、`intl`），可放在任意位置 | `jp` |
| #使用者名稱 | 查詢他人（需對方開啟權限） | `#Sakura` |

牌子字和評級可以連寫，例如 `/完成表 丸將`。

**示例：**

| 指令 |
|------|
| `/完成表 13` |
| `/完成表 14 #Sakura` |
| `/完成表 真 極` |
| `/完成表 丸將` |
| `/完成表 丸 將 #Sakura` |
| `/完成表 祭 將 jp` |

::: tip 跨區服查表
伺服器參數只決定查看哪個區服的曲目表，成績一律來自（被查詢者）透過 `/切換伺服器` 選定的區服。例如國際服玩家傳送 `/完成表 祭 將 jp`，看到的是日服的祭牌曲目，填入的是國際服成績。該區服有、而成績所在區服尚未實裝的譜面會標為「未實裝」，與未遊玩區分開來。
:::

## 上分查詢

查詢在目前 Rating 下，打哪些曲目可以提升 Rating。

**指令：** `/上分 <等級或定數> <分數> [頁數]`

**參數：**

| 參數 | 說明 | 示例 |
|------|------|------|
| 等級或定數 | 目標等級或定數 | `14`、`13.7` |
| 分數 | 目標分值 | `10` |
| 頁數 | 可選，分頁查詢 | `2` |

支援透過 `#使用者名稱` 查詢他人（需對方允許 B50 查詢）。

**示例：**

| 指令 |
|------|
| `/上分 14 5` |
| `/上分 13.7 9 2` |

::: tip
結果圖會區分兩種加分：**Rating** 為達成該難度目標後遊戲整體 Rating 提升的點數；**單曲 ra** 為該譜面單曲 ra 提升的點數（供已達成理論 Rating 的玩家參考）。
:::

::: tip 圖中還包含
- **Rating 趨勢**（僅日服 / 國際服）：結果圖上方顯示近 30 天的 Rating 淨變化、上分局數與天數、單日與單局最高，以及標出每次上分漲幅的 Rating 曲線。查詢他人時需對方允許分數查詢，否則不顯示這一塊。
- **個人化推薦**：附上一張推薦的上分譜面，更多目標見下方的[上分目標推薦](#上分目標推薦)。
:::

### 新版本加分模式

查看本服最新版本新增的曲目中，哪些可以為你的 Rating 加分。該模式整圖展示，不分頁。

**指令：** `/上分 new`

只要參數中包含 `new` 即進入此模式，其餘參數將被忽略。

### 上分目標推薦

根據你的成績，為舊版本、新版本各推薦 3 個適合你的上分目標，標出目標評級、達成後的 Rating 增加量與推薦理由（如「距 SSS 差 0.20%」「同定數中偏簡單」「譜型與個人傾向相符」）。

**指令：** `/上分 推薦`

只要參數中包含 `推薦` 即進入此模式，其餘參數將被忽略。

::: tip
- 推薦依 Rating 增加量與相對難易排序，不代表一定能夠達成。已建立[譜型傾向](/zh-TW/commands/analysis#譜型傾向)時會參考個人傾向，否則只依譜面難度修正。
- 需要有一定數量接近你水準的成績才能給出推薦；成績不足時，可以改用 `/上分 <等級> <分數>`，或傳送 `/練習` 查看補測推薦。
:::
