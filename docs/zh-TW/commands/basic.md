## 隨機歌曲

隨機推薦一首曲目，可按類型、難度顏色、等級篩選。

**指令：** `/隨機歌曲 [類型] [顏色] [等級]`

**參數：**

| 參數 | 說明 | 可選值 |
|------|------|--------|
| 類型 | 曲目類型（可選） | `dx`、`sd` |
| 顏色 | 難度顏色（可選） | `綠`、`黃`、`紅`、`紫`、`白` |
| 等級 | 等級（可選） | `12`、`13+` 等 |

**示例：**

| 指令 |
|------|
| `/隨機歌曲 dx 紫 14` |
| `/隨機歌曲 13+` |
| `/隨機歌曲 sd` |

::: tip
參數順序不固定，輸入時可任意組合，例如 `/隨機歌曲 14 dx` 和 `/隨機歌曲 dx 14` 效果相同。
:::

## 切換語言

切換 Bot 的回覆語言。

**指令：** `/lang [語言代碼]`

**參數：**

| 語言代碼 | 說明 |
|----------|------|
| `zh`（或 `cn`） | 簡體中文（預設） |
| `zh-Hant`（或 `tw`） | 繁體中文（台灣） |
| `zh-Hant-HK`（或 `hk`） | 繁體中文（香港） |
| `en`（或 `english`） | English |
| `ja`（或 `jp`） | 日本語 |

不帶參數執行時，顯示目前語言設定。

**示例：**

| 指令 | 說明 |
|------|------|
| `/lang` | 查看目前語言 |
| `/lang zh-Hant` | 切換到繁體中文 |
| `/lang en` | 切換到英文 |

## 伺服器狀態

查看 maimai DX 各區服的即時線上狀態與心跳監控。

**指令：** `/舞萌狀態`

**別名：** `伺服器狀態`、`maimai狀態`

---

## 區服功能

列出你目前所在區服的專屬指令。

**指令：** `/區服功能`

**說明：** 部分功能只對特定區服開放，本指令會列出目前區服可用的專屬指令；若目前區服沒有專屬功能，會提示可透過 `/切換伺服器` 更換區服。

| 區服 | 專屬指令 |
|------|----------|
| 日服（JP） | `/aime` — 查看／切換 Aime 卡片欄位 |
| 國服（CN） | `/pc50` — 遊玩次數前 50 的成績 |
