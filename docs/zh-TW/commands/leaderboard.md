# 排行榜

## 全域單曲排行

查詢全平台（所有玩家）的單曲達成率排名。

**指令：** `/排行 <曲目ID或曲名> [難度顏色] [區服]`

**參數：**

| 參數 | 說明 | 預設值 |
|------|------|--------|
| 曲目ID或曲名 | 數字 ID 或歌曲名稱/別名 | — |
| 難度顏色 | `綠`、`黃`、`紅`、`紫`、`白` | 紫（Master） |
| 區服 | `cn`、`jp`、`intl` | 全區 |

**示例：**

| 指令 |
|------|
| `/排行 11451` |
| `/排行 潘多拉` |
| `/排行 11451 紫` |
| `/排行 11451 白 jp` |
| `/排行 11451 紫 cn` |

::: tip 圖中包含
該譜面的成績分佈（全服或本群）。
:::

## 群組內單曲排行

查詢目前群組內已加入排行榜的玩家的單曲達成率排名。

**指令：** `/群排行 <曲目ID或曲名> [難度顏色] [區服] [頁碼]`

**參數與 `/排行` 相同**，另可在最後加上頁碼查看後面的名次。區服參數還可以寫 `all`，在大陸區、日本區、國際區之外一併列出[落雪查分器](/zh-TW/commands/account#lxns)、[自訂資料來源](/zh-TW/guide/custom-data-source)等第三方來源的成績：同一玩家有大陸區、日本區或國際區成績時以這些為準，沒有時才使用第三方來源，並在榜上標註來源。

**示例：**

| 指令 |
|------|
| `/群排行 11451` |
| `/群排行 潘多拉 紫` |
| `/群排行 11451 白 cn` |
| `/群排行 11451 all` |
| `/群排行 11451 2` |

::: tip 翻頁
`/群排行` 與 `/群rating` 每頁顯示 10 名，圖中會提示翻頁指令；能顯示按鈕的平台可直接點擊按鈕翻頁。你自己的名次及前後幾名只在第 1 頁顯示。
:::

## 群組內 Rating 排行

查詢目前群組內玩家的 Rating 排名。

**指令：** `/群rating [區服] [頁碼]`

| 參數 | 說明 | 可選值 |
|------|------|--------|
| 區服 | 篩選區服（可選）；`all` 一併計入第三方來源的成績，規則同[群組內單曲排行](#群組內單曲排行) | `cn`、`jp`、`intl`（或中文名）、`all` |
| 頁碼 | 每頁 10 名（可選） | `2` |

**示例：**

| 指令 |
|------|
| `/群rating` |
| `/群rating jp` |
| `/群rating 大陸區` |
| `/群rating all` |
| `/群rating jp 2` |

::: tip 圖中包含
全群的 Rating 段位分佈，以及總人數、平均分、最高分、中位數等概覽資料。
:::

::: tip 只收新版本記錄
榜上每位玩家都會顯示最近一次更新記錄的時間。所在區服的大版本上線後還沒更新過記錄的玩家，暫不計入排名、段位分佈與人數統計，圖中會另外提示未更新的人數。如果你自己的記錄已過期，更新記錄後即可上榜。
:::

## 加入群組榜

在群組內更新資料，或查詢 B50、B40、AP50、PC50 時，會自動加入目前群組的排行榜。退出後想重新加入，或想不經查詢直接加入時，使用此指令。

**指令：** `/加入群榜`

---

## 退出群組榜

從目前群組的排行榜中退出。

**指令：** `/退出群榜`

---

## 群榜管理（群主 / 管理員）

群主或管理員可將成員移出本群排行榜，或將其恢復。

::: info 僅 QQ 平台
此功能僅 QQ 平台的群主 / 管理員可用。
:::

**指令：** `/踢出群榜 <#查分器ID或#使用者名稱>`、`/恢復群榜 <#查分器ID或#使用者名稱>`

**別名：** 踢出群榜 = `移出群榜`；恢復群榜 = `移回群榜`

**說明：** 目標成員需照抄群排行榜上其 `#` 開頭的查分器 ID 或使用者名稱。被移出的成員無法自行重新加入，須由管理員使用 `/恢復群榜` 恢復。

**示例：**

| 指令 | 說明 |
|------|------|
| `/踢出群榜 #mc00000` | 將該成員移出本群排行榜 |
| `/踢出群榜 #Sakura` | 同上，使用使用者名稱 |
| `/恢復群榜 #mc00000` | 恢復該成員的本群排行榜 |
