# 排行榜

## 全域單曲排行

查詢全平台（所有玩家）的單曲達成率排名。

**指令：** `/排行 <曲目ID或曲名> [難度顏色] [區服]`

**參數：**

| 參數 | 說明 | 預設值 |
|------|------|--------|
| 曲目ID或曲名 | 數字 ID 或歌曲名稱/別名 | — |
| 難度顏色 | `綠`、`黃`、`紅`、`紫`、`白` | 紫（Master） |
| 區服 | `cn`、`jp`、`intl` | 全區 |

**示例：**

| 指令 |
|------|
| `/排行 11451` |
| `/排行 11451 紫` |
| `/排行 11451 白 jp` |
| `/排行 11451 紫 cn` |

::: tip
`/排行` 與 `/群排行` 圖現已附帶該譜面的**成績分佈**（全服與本群）。
:::

---

## 群組內單曲排行

查詢目前群組內已加入排行榜的玩家的單曲達成率排名。

**指令：** `/群排行 <曲目ID或曲名> [難度顏色] [區服]`

**參數與 `/排行` 相同。**

**示例：**

| 指令 |
|------|
| `/群排行 11451` |
| `/群排行 11451 白 cn` |

---

## 群組內 Rating 排行

查詢目前群組內玩家的 Rating 排名。

**指令：** `/群rating [區服]`

| 參數 | 說明 | 可選值 |
|------|------|--------|
| 區服 | 篩選區服（可選） | `cn`、`jp`、`intl` |

**示例：**

| 指令 |
|------|
| `/群rating` |
| `/群rating jp` |

::: tip
群 Rating 排行圖現已附帶全群 Rating **段位分佈**，以及總人數、平均分、最高分、中位數等概覽資料。
:::

---

## 加入群組榜

將自己加入目前群組的排行榜，加入後資料才會出現在 `/群排行` 和 `/群rating` 中。

**指令：** `/加入群榜`

---

## 退出群組榜

從目前群組的排行榜中退出。

**指令：** `/退出群榜`

---

## 群榜管理（群主 / 管理員）

群主或管理員可將成員移出本群排行榜，或將其恢復。

::: info 僅 QQ 平台
此功能僅 QQ 平台的群主 / 管理員可用。
:::

**指令：** `/踢出群榜 <#查分器ID或#使用者名稱>`、`/移回群榜 <#查分器ID或#使用者名稱>`

**別名：** 踢出群榜 = `移出群榜`

**說明：** 目標成員需照抄群排行榜上其 `#` 開頭的查分器 ID 或使用者名稱。被移出的成員無法自行重新加入，須由管理員使用 `/移回群榜` 恢復。

**示例：**

| 指令 | 說明 |
|------|------|
| `/踢出群榜 #mc00000` | 將該成員移出本群排行榜 |
| `/踢出群榜 #Sakura` | 同上，使用使用者名稱 |
| `/移回群榜 #mc00000` | 恢復該成員的本群排行榜 |
