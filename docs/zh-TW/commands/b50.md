# maimai B50 查詢與生成

McMai 的 Best 50 功能會依據已同步的遊玩紀錄生成成績圖，並提供 B40、AP50、PC50 和好友 PK 等延伸查詢。開始前，請先[完成資料更新並選擇區服](/zh-TW/guide/score-tracking)。

## 查詢方法

1. 依照所在區服更新成績資料。
2. 確認目前區服為 CN、JP 或 INTL。
3. 傳送 `/b50`；查詢他人時在指令後加入 `#使用者名稱`。

## Best 50

查詢你的 Best 50 成績（舊版本 Top 35 + 新版本 Top 15）。

**指令：** `/b50`

支援透過 `#使用者名稱` 查詢他人資料（需對方開啟查詢權限）。

**示例：**

| 指令 |
|------|
| `/b50` |
| `/b50 #某人` |

::: tip 圖中包含
- 玩家資訊、遊玩統計，以及 Rating 分佈與評級 / 連擊 / 同步 / DX 星統計。
- **Rating 走勢**（僅日服 / 國際服）：概要列中顯示近 30 天的 Rating 變化，完整記錄可用 [`/rating記錄`](/zh-TW/commands/score#rating-變化) 查看。
- **譜型傾向**：成績足夠時，分析區會顯示譜型傾向雷達，標出你在各類譜面上的相對表現與相對弱項，詳見[譜面分析與練習](/zh-TW/commands/analysis#譜型傾向)。成績不夠時不顯示，可傳送 `/練習` 查看補測推薦。
:::

::: tip 理論值 B50
想知道全曲理論值的 Rating 有多高？傳送 `/b50 #intlmaxscore` 查看國際服理論值 B50，日服用 `/b50 #jpmaxscore`，中國服用 `/b50 #maxscore`。理論值會隨曲庫更新自動重建。
:::

## PK B50

與指定使用者在共同譜面上對決，比較雙方的 Rating。

**指令：** `/pk50 [#使用者名稱]`

- 指定對手：`/pk50 #Sakura`
- 不指定時：隨機匹配同區服、與你至少有 10 首共同譜面的玩家（在群組內傳送時只從本群組匹配），優先選擇 Rating 與你相差 100 以內的玩家

**示例：**

| 指令 | 說明 |
|------|------|
| `/pk50 #Sakura` | 與 Sakura PK |
| `/pk50` | 隨機匹配對手 |

**對戰規則：**

1. **考卷**：從雙方都打過的譜面（不含宴譜）中，兩人輪流挑選自己 RA 最高的譜面，湊成舊版本至多 35 首 + 新版本至多 15 首。雙方各帶一半自己拿手的譜面進考卷，誰發起都不佔便宜。
2. **判定**：比較雙方在考卷上的 Rating 總和；總和相同時比逐譜勝場。單張譜面先比 RA，RA 相同再比達成率。
3. 共同譜面不足 10 首時無法開局。
4. **跨服對戰**：雙方不在同一區服時，每張譜面統一按 JP > INTL > CN 的順序取定數。

::: tip 結果圖中包含
- 雙方銘牌（遊戲內的名牌框、段位與階級）與比分，以及各自本人的 B50 Rating（僅供參考，不列入判定）。
- 逐張譜面左右比較達成率、評級與 RA，底部附逐譜 RA 差值圖與譜面勝負。
- 在[頂板樣式](/zh-TW/commands/settings#頂板樣式設定)中隱藏了暱稱的玩家，圖上也會隱藏暱稱。
:::

## 更新 B50 資料

從 maimai NET 同步你的最新 B50 資料到本機快取。

**指令：** `/更新記錄`

::: tip 中國服用戶透過掃碼更新
中國服用戶使用舞萌 ｜ 中二 公眾號內「玩家二維碼」功能獲取 QR Code，長按 QR Code 解析後將含有 `SGWCMAID` 字樣的內容發送到 Bot，會自動觸發中國服 B50 資料更新。
:::
