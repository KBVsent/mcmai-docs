# 譜面分析與練習

McMai 會分析每張譜面的結構，並結合你的成績給出譜型傾向、練習推薦與[上分目標](/zh-TW/commands/tables#上分目標推薦)。

## 譜面結構

查歌、譜面分析、練習推薦等結果圖中會用到以下概念：

| 概念 | 說明 |
|------|------|
| 九維 | 從九個方面描述譜面：手速、耐力、大範圍位移、雙手分工、滑條精度、滑條讀譜、螢幕操作、節奏解析、視覺解析。以全庫譜面為參照得出，用雷達圖呈現 |
| 結構定數 | 根據譜面內容得出的定數，顯示在雷達中心，只反映譜面內容本身的難度，不含個人差等因素。查歌圖的 Note 分佈表會把它列在擬合定數旁，沒有擬合定數的曲目只顯示結構定數 |
| 譜面標籤 | 譜面中出現的配置，如縱連、交互，依在譜面中所佔的時長排列 |
| 關聯譜面 | 結構相近的其他譜面 |

---

## 譜面分析

在一張圖裡列出一首歌所有難度的譜面結構，不需要綁定成績。

**指令：** `/譜面分析 <曲目ID或曲名>`

**示例：**

| 指令 |
|------|
| `/譜面分析 11451` |
| `/譜面分析 系ぎて` |

::: tip
圖底部會給出該曲主要配置的練習指令（如 `/練習 縱連`），在支援按鈕的平台上也可以直接點擊「練習」按鈕。`/查歌` 結果中的「譜面分析」按鈕會開啟這張圖。
:::

## 練習推薦

根據你的譜型傾向推薦練習譜面，顯示各譜面的九維結構與你目前的成績，推薦每天輪換。僅可查詢自己。

**指令：** `/練習 [能力或配置] [難度範圍]`

**參數：**

| 參數 | 說明 | 示例 |
|------|------|------|
| 能力或配置 | 可選。能力為九維之一；配置為查歌、譜面分析中顯示的譜面標籤。不填時練習相對較弱的兩項能力 | `手速`、`縱連` |
| 難度範圍 | 可選。等級或定數，用 `-` 連接上下限，只寫一個時表示單一等級；不填時依現有成績估算 | `12-13`、`13`、`13.5-14.0` |

能力或配置與難度範圍不分先後。不帶小數點的數字按等級理解，例如 `12-13` 表示 12、12+、13 這幾個等級。

**示例：**

| 指令 | 說明 |
|------|------|
| `/練習` | 依相對弱項推薦 |
| `/練習 手速` | 只練手速 |
| `/練習 縱連 13` | 13 級中帶縱連配置的譜面 |
| `/練習 12-13` | 在 12～13 級中推薦 |

::: tip 不綁定成績也能用
依配置練習（如 `/練習 縱連`），或指定了難度範圍時，不需要綁定成績，新玩家也可以使用。
:::

::: tip 補測推薦
譜型傾向需要足夠的成績樣本才能建立。樣本不足時，`/練習` 會改為推薦一組「補測譜面」：完成並更新成績後，樣本充足時 B50 會顯示譜型傾向，本指令也會切換為練習推薦。補測譜面只用於補充成績樣本，與能力強弱無關。
:::

## 譜型傾向

成績足夠時，B50 圖的分析區會顯示譜型傾向雷達：雷達大小代表你的整體水準，各維度的偏離代表你在該類譜面上的相對表現，並標出相對弱項。

- 只根據你自己的最高成績計算（使用全部可用成績，而不只是 B50），比較的是你自身各類譜面之間的表現，不與其他玩家比較。
- 只標出相對弱項，不標強項；螢幕操作不列入評估。
- 成績樣本不足時不顯示，可傳送 `/練習` 查看補測推薦。
- 建立後會用於 `/練習`、[`/上分 推薦`](/zh-TW/commands/tables#上分目標推薦) 的排序，以及 [`/今日舞萌`](/zh-TW/commands/basic#今日運勢) 的推薦譜面。
