# 账号与服务器

## 绑定账号

**指令：** `/绑定`

**说明：** 执行后会生成一个专属绑定链接，在浏览器中打开，选择区服后按页面提示完成绑定。绑定 SEGA ID 或授权落雪查分器后会立即更新一次成绩，并可勾选同时把 McMai 的当前区服切换过去。

绑定链接只会发到仅你本人可见的地方：私聊、QQ 群里仅你可点击的按钮、Discord `/bind` 斜杠指令的私密回复。其他群聊场景下，Bot 会提示你私聊发送 `/绑定`。

| 区服 | 方式 |
|------|------|
| 日本服 | 绑定 SEGA ID，或使用[书签](/guide/bookmarklet-update)更新 |
| 国际服 | 绑定 SEGA ID，提交[登录令牌](#intl-token)，或使用[书签](/guide/bookmarklet-update)更新 |
| 国服 | 开通 [NET 微信授权](/guide/cn-net-update)，[发送 MAID](#maid)，或授权[落雪查分器](#lxns) |

三个区服还可以通过[自定义数据源](/guide/custom-data-source)上传成绩文件。

::: warning 注意
绑定链接 10 分钟内有效，每次执行 `/绑定` 都会生成新的链接。请勿分享给他人。
:::

::: tip 管理已关联的账号
绑定页会列出各区服已关联的游戏账号，点选即可切换当前使用的账号（效果同 [`/选卡`](#aime)）。不再需要某个账号时，可在绑定页单独解绑：解除关联后成绩数据保留，之后用同一账号再次更新即可重新关联。解绑账号密码或落雪查分器更新的账号时，已保存的账号密码或落雪授权可能一并删除，确认框会列出具体影响。
:::

## 国际服登录令牌 {#intl-token}

用 X、Facebook 或 LINE 登录 maimai DX NET、没有 SEGA ID 密码的国际服玩家，可以改用登录令牌绑定，之后同样使用 `/更新记录`。

发送 `/绑定`，在绑定页选择「国际服」→「令牌」，粘贴含 `clal` 的 cookie。获取方法可点击输入框旁的「问 ChatGPT 如何获取」，按自己的设备询问。

::: warning 令牌会因退出登录失效
在任何设备上退出 maimai DX NET 登录，都会让令牌失效，需要重新提交。令牌等同登录凭据，不要发给他人。
:::

## 用书签更新成绩

日本服和国际服可使用浏览器已登录的 NET 会话更新成绩，无需向 McMai 提交 SEGA ID 和密码。

发送 `/绑定`，在绑定页选择区服和「书签」方式，生成并安装书签。安装后在已登录的 maimai NET 页面运行。

完整图解见[书签更新教程](/guide/bookmarklet-update)，包含电脑 Chrome、iPhone Safari 和 Android Chrome 的安装与使用步骤。

书签代码包含账号上传凭证；重新生成后，旧代码立即失效。

## 国服 MAID 更新 {#maid}

私聊 Bot 或在群内 @Bot 发送 MAID（`SGWCMAID` 开头的 84 位字符串），也可以在绑定页「国服」→「MAID」中粘贴，即可更新国服成绩。国服 [PC50](/commands/b50#pc50) 所需的游玩次数只随 MAID 更新获取。

::: details 如何获取 MAID？
1. 进入「舞萌 | 中二」公众号
2. 点击「获取二维码」
3. 打开二维码界面
4. 长按扫描，复制出现的 `SGWCMAID` 开头字符串
:::

## 落雪查分器 {#lxns}

国服玩家可以授权落雪查分器，用落雪上的成绩使用 B50 等查询功能。发送 `/绑定`，在绑定页选择「国服」→「落雪」，点击「前往落雪查分器授权」完成授权。

- 查询自己的成绩时会自动同步落雪上的新成绩，也可以发送 `/更新记录` 立即同步。
- 落雪账号与国服的其他账号列在一起，用 [`/选卡`](#aime) 或在绑定页切换。
- 落雪的数据不含游玩记录和游玩次数，无法使用 `/最近游玩`、`/rating变化` 与 `/pc50`。
- 落雪的数据默认不计入排行榜，群排行与群 Rating 排行加上 [`all` 参数](/commands/leaderboard#群内单曲排行)可一并查看。

授权失效时，Bot 会提示发送 `/绑定` 重新授权，已同步的成绩保留。

## 多平台数据互通

同一个游戏账号（同一张卡）在不同平台绑定后，数据自动互通：**只需在任意一个平台更新一次成绩，其余平台同步可见**，不必在每个平台各更新一遍。

::: tip 提示
互通的判定单位是游戏账号，不是平台身份。绑定不同卡片的账号会各自独立，不会互通。
:::

## 查成绩时自动更新 {#auto-update}

查询自己的成绩时，如果数据超过 1 小时未更新，Bot 会先更新再出结果。落雪查分器不受 1 小时限制，查询时有新成绩就会同步。

**指令：** `/自动更新 [开|关]`

- 不带参数：查看当前状态。默认开启。
- 适用于绑定了 SEGA 账号（日本服、国际服）、国际服登录令牌或落雪查分器的数据。书签、国服 NET 与 MAID、自定义数据源的数据需要按原方式手动更新。
- 只在查询自己时触发，查询他人不会更新对方的数据。查歌与今日运势不会触发。
- 日本服、国际服查看 `/最近游玩` 与 `/rating变化` 时同样会自动更新。

**示例：**

| 指令 | 说明 |
|------|------|
| `/自动更新` | 查看当前状态 |
| `/自动更新 关` | 关闭，之后需要时用 `/更新记录` 手动更新 |
| `/自动更新 开` | 重新开启 |

::: warning 更新期间请勿登录 NET
通过 SEGA 账号或登录令牌更新（包括自动更新）时，排队与更新期间请勿手动登录 maimai DX NET。更新完成后最近游玩记录会在后台继续获取，接下来几分钟内同样请勿登录。
:::

## 注销账号

清除你的全部登录凭据与成绩记录。

**指令：** `/注销账号 [确认]`

::: danger 不可恢复
注销会一次性清除以下内容，且**无法恢复**：

- SEGA 账号登录凭据（SEGA ID、密码或登录令牌）
- 落雪查分器授权、自定义数据源的上传令牌
- 你在所有区服的成绩记录

为防止误操作，需二次确认：先发送 `/注销账号` 查看将删除的内容，再发送 `/注销账号 确认` 执行。确认请求 **5 分钟** 内有效，超时需重新发起。有成绩更新正在进行时无法注销，请等更新完成后再发送。
:::

只想移除某一个游戏账号、保留其他数据时，请在绑定页单独解绑该账号，见[管理已关联的账号](#绑定账号)。

**示例：**

| 指令 | 说明 |
|------|------|
| `/注销账号` | 查看将删除的内容并发起注销请求 |
| `/注销账号 确认` | 确认并执行注销（5 分钟内有效） |

## 选卡 {#aime}

在当前区服已关联的游戏账号之间切换。用不同方式更新过的数据（如国服的 NET 与 MAID、落雪查分器、自定义数据源）各是一个账号，互不覆盖，查询时使用当前选中的账号。

**指令：** `/选卡 [序号]`

**别名：** `切换账号`、`aime`、`卡片`、`切卡`

**说明：**

- `/选卡`：列出当前区服下的账号，标注当前账号、Rating、更新方式与最近更新时间。
- `/选卡 <序号>`：切换到指定账号。
- 日本服绑定了 SEGA ID 时，列表还会附上该 SEGA ID 下尚未更新过的 Aime 卡片。选中这类卡片后，下次 `/更新记录` 更新这张卡，完成后自动切换到它。

用某种方式更新成绩后，会自动切换到该方式对应的账号。也可以在绑定页的账号列表中点选切换。

**示例：**

| 指令 | 说明 |
|------|------|
| `/选卡` | 查看当前区服的账号列表 |
| `/选卡 2` | 切换到第 2 个账号 |

## 设置用户名

设置一个便于他人通过 `#用户名` 查询你数据的标识符。

**指令：** `/用户名 [用户名|清除]`

**示例：**

| 指令 | 说明 |
|------|------|
| `/用户名 Sakura` | 设置用户名为 Sakura |
| `/用户名` | 查看当前用户名（未设置时显示查分器 ID） |
| `/用户名 清除` | 清除用户名 |

**用户名规则：** 可使用汉字、平假名、片假名、英文字母和数字，不能为纯数字，最多 10 个字符。输入的半角片假名、全角英文数字会自动转换；与他人用户名形近难辨的名字无法设置。

**查询标识符说明：**

每位用户都有一个系统自动分配的**查分器 ID**（`#mc` 开头的短 ID），即使未设置用户名也可使用它被他人查询。设置用户名后，他人可以通过 `#用户名` 查询你，也可以继续使用查分器 ID。

::: warning 注意
在使用用户名作为查询参数时，用户名前一定要加 `#`。

例如 `/b50 #Sakura`，而不是 `/b50 Sakura`。
:::

::: tip 审核机制
用户名设置后需经过审核：

- **审核中**：可以用 `#用户名` 被他人查询，但显示时用户名会被部分遮盖
- **审核通过**：用户名完整显示
- **审核不通过**：用户名将被自动删除，需重新设置

用户名每 **3 天** 只能修改一次，请谨慎设置。
:::

## 隐私设置

控制他人能否查询你的游戏数据。

**指令：** `/隐私设置 <动作> [目标]`

**动作：**

| 动作 | 说明 |
|------|------|
| `查看` | 查看当前隐私设置 |
| `开启` | 允许他人查询指定目标 |
| `关闭` | 禁止他人查询指定目标 |
| `重置` | 将所有查询权限恢复为默认（全部允许），无需目标 |

**目标：**

| 目标 | 说明 |
|------|------|
| `查询` | 总开关，控制所有查询权限 |
| `b50查询` | Best 50 等各类 50 查询，以及 PK、上分查询 |
| `分数查询` | 成绩（info）、最近游玩、Rating 变化查询 |
| `进度查询` | 完成表、进度、分类进度、分数列表查询 |

::: tip
关闭 `查询`（总开关）后，他人将无法查询你的任何数据，优先级高于其他单项设置。排行榜不受隐私设置影响。
:::

**示例：**

| 指令 | 说明 |
|------|------|
| `/隐私设置 查看` | 查看当前各项隐私状态 |
| `/隐私设置 关闭 查询` | 禁止他人查询你的所有数据 |
| `/隐私设置 关闭 分数查询` | 单独禁止他人查询你的成绩 |
| `/隐私设置 开启 b50查询` | 重新允许他人查询你的 Best 50 |
| `/隐私设置 重置` | 恢复所有查询权限为默认值 |

## 好友管理

管理你的 McMai 好友列表，好友列表用于 PK 功能。

**指令：** `/好友 [动作] [参数]`

**别名：** `好友管理`

**动作：**

| 动作 | 说明 | 参数 |
|------|------|------|
| `列表` | 查看好友列表 | — |
| `添加` | 添加好友 | `#用户名` 或 `#查分器ID`，可再加槽位号（1～3）覆盖该槽位 |
| `删除` | 删除好友 | 槽位号（1～3） |

**示例：**

| 指令 | 说明 |
|------|------|
| `/好友 列表` | 查看好友列表 |
| `/好友 添加 #Sakura` | 添加名为 Sakura 的好友 |
| `/好友 添加 #Sakura 1` | 在槽位号为 1 的位置覆盖添加名为 Sakura 的好友 |
| `/好友 删除 1` | 删除槽位号为 1 的好友 |
