# 谱面分析与练习

McMai 会分析每张谱面的结构，并结合你的成绩给出谱型倾向、练习推荐与[上分目标](/commands/tables#上分目标推荐)。

## 谱面结构

查歌、谱面分析、练习推荐等结果图中会用到以下概念：

| 概念 | 说明 |
|------|------|
| 九维 | 从九个方面描述谱面：手速、耐力、大范围位移、双手分工、滑条精度、滑条读谱、屏幕操作、节奏解析、视觉解析。以全库谱面为参照得出，用雷达图展示 |
| 结构定数 | 根据谱面内容得出的定数，显示在雷达中心，只反映谱面内容本身的难度，不含个人差等因素。查歌图的 Note 分布表会把它列在拟合定数旁，没有拟合定数的曲目只显示结构定数 |
| 谱面标签 | 谱面中出现的配置，如纵连、交互，按在谱面中所占的时长排列 |
| 关联谱面 | 结构相近的其他谱面 |

## 谱面分析

在一张图里列出一首歌所有难度的谱面结构，不需要绑定成绩。

**指令：** `/谱面分析 <曲目ID或曲名>`

**示例：**

| 指令 |
|------|
| `/谱面分析 11451` |
| `/谱面分析 系ぎて` |

::: tip
图底部会给出该曲主要配置的练习指令（如 `/练习 纵连`），在支持按钮的平台上也可以直接点击「练习」按钮。`/查歌` 结果中的「谱面分析」按钮会打开这张图。
:::

## 练习推荐

根据你的谱型倾向推荐练习谱面，显示各谱面的九维结构与你的当前成绩，推荐每天轮换。仅可查询自己。

**指令：** `/练习 [能力或配置] [难度范围]`

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| 能力或配置 | 可选。能力为九维之一；配置为查歌、谱面分析中显示的谱面标签。不填时练习相对较弱的两项能力 | `手速`、`纵连` |
| 难度范围 | 可选。等级或定数，用 `-` 连接上下限，只写一个时表示单个等级；不填时根据现有成绩估算 | `12-13`、`13`、`13.5-14.0` |

能力或配置与难度范围不分先后。不带小数点的数字按等级理解，例如 `12-13` 表示 12、12+、13 这几个等级。

**示例：**

| 指令 | 说明 |
|------|------|
| `/练习` | 按相对弱项推荐 |
| `/练习 手速` | 只练手速 |
| `/练习 纵连 13` | 13 级中带纵连配置的谱面 |
| `/练习 12-13` | 在 12～13 级中推荐 |

::: tip 不绑定成绩也能用
按配置练习（如 `/练习 纵连`），或指定了难度范围时，不需要绑定成绩，新玩家也可以使用。
:::

::: tip 补测推荐
谱型倾向需要足够的成绩样本才能建立。样本不足时，`/练习` 会改为推荐一组「补测谱面」：完成并更新成绩后，样本充足时 B50 会显示谱型倾向，本指令也会切换为练习推荐。补测谱面只用于补充成绩样本，与能力强弱无关。
:::

## 谱型倾向

成绩足够时，B50 图的分析区会显示谱型倾向雷达：雷达大小表示你的整体水平，各维度的偏离表示你在该类谱面上的相对表现，并标出相对弱项。

- 只根据你自己的最高成绩计算（使用全部可用成绩，而不只是 B50），比较的是你自身各类谱面之间的表现，不与其他玩家比较。
- 只标出相对弱项，不标强项；屏幕操作不参与评估。
- 成绩样本不足时不显示，可发送 `/练习` 查看补测推荐。
- 建立后会用于 `/练习`、[`/上分 推荐`](/commands/tables#上分目标推荐) 的排序，以及 [`/今日舞萌`](/commands/basic#今日运势) 的推荐谱面。
