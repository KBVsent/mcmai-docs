# 排行榜

## 全局单曲排行

查询全平台（所有玩家）的单曲达成率排名。

**指令：** `/排行 <曲目ID或曲名> [难度颜色] [区服]`

**参数：**

| 参数 | 说明 | 默认值 |
|------|------|-----|
| 曲目ID或曲名 | 数字 ID 或歌曲名称/别名 | — |
| 难度颜色 | `绿`、`黄`、`红`、`紫`、`白` | 紫（Master） |
| 区服 | `cn`、`jp`、`intl` | 全区 |

**示例：**

| 指令 |
|------|
| `/排行 11451` |
| `/排行 潘多拉` |
| `/排行 11451 紫` |
| `/排行 11451 白 jp` |
| `/排行 11451 紫 cn` |

::: tip
`/排行` 与 `/群排行` 图现已附带该谱面的**成绩分布**（全服与本群）。
:::

---

## 群内单曲排行

查询当前群内已加入排行榜的玩家的单曲达成率排名。

**指令：** `/群排行 <曲目ID或曲名> [难度颜色] [区服]`

**参数与 `/排行` 相同。**

**示例：**

| 指令 |
|------|
| `/群排行 11451` |
| `/群排行 潘多拉 紫` |
| `/群排行 11451 白 cn` |

---

## 群内 Rating 排行

查询当前群内玩家的 Rating 排名。

**指令：** `/群rating [区服]`

| 参数 | 说明 | 可选值 |
|------|------|--------|
| 区服 | 筛选区服（可选） | `cn`、`jp`、`intl`（或中文名） |

**示例：**

| 指令 |
|------|
| `/群rating` |
| `/群rating jp` |
| `/群rating 国服` |

::: tip
群 Rating 排行图现已附带全群 Rating **段位分布**，以及总人数、平均分、最高分、中位数等概览数据。
:::

---

## 加入群榜

将自己加入当前群的排行榜，加入后数据才会出现在 `/群排行` 和 `/群rating` 中。

**指令：** `/加入群榜`

---

## 退出群榜

从当前群的排行榜中退出。

**指令：** `/退出群榜`

---

## 群榜管理（群主 / 管理员）

群主或管理员可将成员移出本群排行榜，或将其恢复。

::: info 仅 QQ 官方群
此功能仅 QQ 官方平台的群主 / 管理员可用。
:::

**指令：** `/踢出群榜 <#查分器ID或#用户名>`、`/恢复群榜 <#查分器ID或#用户名>`

**别名：** 踢出群榜 = `移出群榜` = `gban`；恢复群榜 = `移回群榜` = `gunban`

**说明：** 目标成员需照抄群排行榜上其 `#` 开头的查分器 ID 或用户名。被移出的成员无法自行重新加入，须由管理员使用 `/恢复群榜` 恢复。

**示例：**

| 指令 | 说明 |
|------|------|
| `/踢出群榜 #mc00000` | 将该成员移出本群排行榜 |
| `/踢出群榜 #Sakura` | 同上，使用用户名 |
| `/恢复群榜 #mc00000` | 恢复该成员的本群排行榜 |
