# 排行榜

## 全局单曲排行

查询全平台（所有玩家）的单曲达成率排名。

**指令：** `/排行 <曲目ID或曲名> [难度颜色] [区服]`

**参数：**

| 参数 | 说明 | 默认值 |
|------|------|-----|
| 曲目ID或曲名 | 数字 ID 或歌曲名称/别名 | — |
| 难度颜色 | `绿`、`黄`、`红`、`紫`、`白` | 紫（Master） |
| 区服 | `cn`、`jp`、`intl` | 全区 |

**示例：**

| 指令 |
|------|
| `/排行 11451` |
| `/排行 潘多拉` |
| `/排行 11451 紫` |
| `/排行 11451 白 jp` |
| `/排行 11451 紫 cn` |

::: tip 图中包含
该谱面的成绩分布（全服或本群）。
:::

## 群内单曲排行

查询当前群内已加入排行榜的玩家的单曲达成率排名。

**指令：** `/群排行 <曲目ID或曲名> [难度颜色] [区服] [页码]`

**参数与 `/排行` 相同**，另可在最后加上页码查看后面的名次。区服参数还可以写 `all`，在国服、日本服、国际服之外一并列出[落雪查分器](/commands/account#lxns)、[自定义数据源](/guide/custom-data-source)等第三方来源的成绩：同一玩家有国服、日本服或国际服成绩时以这些为准，没有时才使用第三方来源，并在榜上标注来源。

**示例：**

| 指令 |
|------|
| `/群排行 11451` |
| `/群排行 潘多拉 紫` |
| `/群排行 11451 白 cn` |
| `/群排行 11451 all` |
| `/群排行 11451 2` |

::: tip 翻页
`/群排行` 与 `/群rating` 每页显示 10 名，图中会提示翻页指令；能显示按钮的平台可直接点击按钮翻页。你自己的名次及前后几名只在第 1 页显示。
:::

## 群内 Rating 排行

查询当前群内玩家的 Rating 排名。

**指令：** `/群rating [区服] [页码]`

| 参数 | 说明 | 可选值 |
|------|------|--------|
| 区服 | 筛选区服（可选）；`all` 一并计入第三方来源的成绩，规则同[群内单曲排行](#群内单曲排行) | `cn`、`jp`、`intl`（或中文名）、`all` |
| 页码 | 每页 10 名（可选） | `2` |

**示例：**

| 指令 |
|------|
| `/群rating` |
| `/群rating jp` |
| `/群rating 国服` |
| `/群rating all` |
| `/群rating jp 2` |

::: tip 图中包含
全群的 Rating 段位分布，以及总人数、平均分、最高分、中位数等概览数据。
:::

::: tip 只收新版本记录
榜上每位玩家都会显示最近一次更新记录的时间。所在区服的大版本上线后还没更新过记录的玩家，暂不计入排名、段位分布与人数统计，图中会另行提示未更新的人数。如果你自己的记录已过期，更新记录后即可上榜。
:::

## 加入群榜

在群内更新数据，或查询 B50、B40、AP50、PC50 时，会自动加入当前群的排行榜。退出后想重新加入，或想不经查询直接加入时，使用此指令。

**指令：** `/加入群榜`

---

## 退出群榜

从当前群的排行榜中退出。

**指令：** `/退出群榜`

---

## 群榜管理（群主 / 管理员）

群主或管理员可将成员移出本群排行榜，或将其恢复。

::: info 仅 QQ 平台
此功能仅 QQ 平台的群主 / 管理员可用。
:::

**指令：** `/踢出群榜 <#查分器ID或#用户名>`、`/恢复群榜 <#查分器ID或#用户名>`

**别名：** 踢出群榜 = `移出群榜`；恢复群榜 = `移回群榜`

**说明：** 目标成员需照抄群排行榜上其 `#` 开头的查分器 ID 或用户名。被移出的成员无法自行重新加入，须由管理员使用 `/恢复群榜` 恢复。

**示例：**

| 指令 | 说明 |
|------|------|
| `/踢出群榜 #mc00000` | 将该成员移出本群排行榜 |
| `/踢出群榜 #Sakura` | 同上，使用用户名 |
| `/恢复群榜 #mc00000` | 恢复该成员的本群排行榜 |
