# maimai B50 查询与生成

McMai 的 Best 50 功能会根据已同步的游玩记录生成成绩图，并提供 B40、AP50、PC50 和好友 PK 等延伸查询。开始前，请先[完成数据更新并选择区服](/guide/score-tracking)。

## 查询方法

1. 按照所在区服更新成绩数据。
2. 确认当前区服为 CN、JP 或 INTL。
3. 发送 `/b50`；查询他人时在指令后添加 `#用户名`。

## Best 50

查询你的 Best 50 成绩（旧版本 Top 35 + 新版本 Top 15）。

**指令：** `/b50`

支持通过`#用户名` 查询他人数据（需对方开启查询权限）。

**示例：**

| 指令 |
|------|
| `/b50` |
| `/b50 #某人` |

::: tip 图中包含
- 玩家信息、游玩统计，以及 Rating 分布与评级 / 连击 / 同步 / DX 星统计。
- **Rating 走势**（仅日服 / 国际服）：概要条中显示近 30 天的 Rating 变化，完整记录可用 [`/rating变化`](/commands/score#rating-变化) 查看。
- **谱型倾向**：成绩足够时，分析区会显示谱型倾向雷达，标出你在各类谱面上的相对表现与相对弱项，详见[谱面分析与练习](/commands/analysis#谱型倾向)。成绩不够时不显示，可发送 `/练习` 查看补测推荐。
:::

::: tip 理论值 B50
想知道全曲理论值的 Rating 有多高？发送 `/b50 #maxscore` 查看国服理论值 B50，日服用 `/b50 #jpmaxscore`，国际服用 `/b50 #intlmaxscore`。理论值会随曲库更新自动重建。
:::

## PK B50

与指定用户在共同谱面上对决，比较双方的 Rating。

**指令：** `/pk50 [#用户名]`

- 指定对手：`/pk50 #Sakura`
- 不指定时：随机匹配同区服、与你至少有 10 首共同谱面的玩家（在群内发送时只从本群匹配），优先选择 Rating 与你相差 100 以内的玩家

**示例：**

| 指令 | 说明 |
|------|------|
| `/pk50 #Sakura` | 与 Sakura PK |
| `/pk50` | 随机匹配对手 |

**对战规则：**

1. **考卷**：从双方都打过的谱面（不含宴谱）中，两人轮流挑选自己 RA 最高的谱面，凑成旧版本至多 35 首 + 新版本至多 15 首。双方各带一半自己拿手的谱面进考卷，谁发起都不占便宜。
2. **判定**：比较双方在考卷上的 Rating 总和；总和相同时比逐谱胜场。单张谱面先比 RA，RA 相同再比达成率。
3. 共同谱面不足 10 首时无法开局。
4. **跨服对战**：双方不在同一区服时，每张谱面统一按 JP > INTL > CN 的顺序取定数。

::: tip 结果图中包含
- 双方铭牌（游戏内的姓名框、段位与阶级）与比分，以及各自本人的 B50 Rating（仅供参考，不参与判定）。
- 逐张谱面左右对比达成率、评级与 RA，底部附逐谱 RA 差值图与谱面胜负。
- 在[顶板样式](/commands/settings#顶板样式设置)中隐藏了昵称的玩家，图上也会隐藏昵称。
:::

## 更新 B50 数据

从 maimai NET 同步你的最新 B50 数据到本地缓存。

**指令：** `/更新记录`

::: tip 国服用户通过扫码更新
国服用户使用舞萌 ｜ 中二 公众号内"玩家二维码"功能获取二维码，长按二维码解析后将含有 `SGWCMAID` 字样的内容发送到 Bot，会自动触发国服 B50 数据更新。
:::
