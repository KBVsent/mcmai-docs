# 成绩查询

## 曲目个人游玩数据

查询指定曲目的个人游玩详情，包括达成率、DX 分、FC/FS 状态等。

**指令：** `/info <曲目ID或曲名>`

**参数：**

| 参数 | 说明 |
|------|------|
| 曲目ID或曲名 | 数字 ID 或歌曲名称/别名 |

支持查询他人数据，在指令后加 `#用户名`。

**示例：**

| 指令 |
|------|
| `/info 11451` |
| `/info 潘多拉` |
| `/info 11451 #Sakura` |

::: tip 图中包含
- **我的成绩**：同一账号在多个区服都有成绩时，各区服会并排展示，方便横向对比；某难度在该区服没有对应谱面时显示「无此难度」。
- **好友对比**：加 `#用户名` 查询他人时，对方成绩会与自己主区服的成绩逐难度对比，标出达成率差值（▲/▼）；对方隐藏了查询权限时只显示「私密」。
:::

## 分数线容错

查询指定难度下每种 Note 的扣分值、DX 星级所需 DX 分数的容错范围，以及各评级的 TAP 失误容错。

**指令：** `/分数线 <歌曲ID> [难度颜色]`

**参数：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 歌曲ID | 数字 ID | — |
| 难度颜色 | `绿`、`黄`、`红`、`紫`、`白` | 紫 |

**示例：**

| 指令 |
|------|
| `/分数线 11451` |
| `/分数线 11820 白` |

::: tip 图中包含
- **DX 星级**：达成各 DX 星级所需的 DX 分数容错范围。
- **评级容错**：以理论值 101% 为基准，达成 SSS+ / SSS / SS+ / SS / S+ / S 各评级时，全程仅 TAP 粉 / TAP 绿 / TAP Miss 单一失误的最大可容许个数（三档互斥）。
:::

## 识分（成绩图分析）

发送一张成绩图，自动识别达成率与 Note 判定分布，并**反推 BREAK 的细分构成**（绝赞 / 50 落 / 100 落等）与逐 Note 的失分明细。

**指令：** `/识分`

**别名：** `识成绩`

**用法：**

- 发送指令时**同时附带**一张成绩图；
- 或**引用**一条含成绩图的消息，再艾特 Bot 并发送指令。

**结果图包含：**

- 匹配到的曲目、难度与 DX 星级、连击评价（FC / FC+ / AP / AP+）
- 判定分布 & 失分表：每格显示「数量 / 合计扣分 / 单个扣分」
- 反推出的 BREAK 细分；若存在多组数学上等价的解，会一并列出

### 手动修正模式

当图片压缩过度、部分数字识别错误时，可以不带图片、直接用参数调用，手动给出正确数值。

**指令：** `/识分 id=<歌曲ID> ach=<达成率> tap=<CP/P/GR/GD/MS> hold=... slide=... touch=... break=...`

**参数：**

| 参数 | 说明 | 是否必填 |
|------|------|----------|
| `id` | 歌曲 ID（数字） | 与 Note 分布至少填其一 |
| `ach` | 达成率，范围 0～101，如 `100.8623` | 必填 |
| `tap` / `hold` / `slide` / `break` | 各类型的 5 档判定数，按 `CP/P/GR/GD/MS` 顺序用 `/` 分隔 | 必填 |
| `touch` | 同上；该谱面无 TOUCH 时可省略（按全 0 处理） | 可选 |

参数名固定为英文（`ach` 也可写作 `达成率` / `acc`），顺序不限。

**示例：**

```
/识分 id=834 ach=100.8623 tap=380/0/0/0/0 hold=52/0/0/0/0 slide=90/0/0/0/0 touch=0/0/0/0/0 break=47/0/1/0/0
```

::: tip 提高识别成功率
- 尽量发送**原图**，并确保游戏画面**顶部的 Note 分布**清晰完整。
- 识别失败时，Bot 会回复带有已识别数值的指令模板，复制后改正错误的数字重新发送即可；在 Discord 上则可直接点击「✏️ 修正参数」按钮填写。
:::

::: warning 限制
- 暂不支持宴谱（UTAGE）成绩推算。
- 若同一组 Note 分布在曲库中对应多首曲目，需要用 `id=` 指定具体谱面。
:::

## 谱面统计

查询指定曲目各难度的 AP 率、FC 率、游玩率等统计数据。

**指令：** `/谱面统计 <曲目ID或曲名> [区服]`

**参数：**

| 参数 | 说明 | 可选值 |
|------|------|--------|
| 曲目ID或曲名 | 数字 ID 或歌曲名称/别名 | — |
| 区服 | 筛选区服（可选） | `cn`、`jp`、`intl` |

**示例：**

| 指令 |
|------|
| `/谱面统计 11451` |
| `/谱面统计 潘多拉` |
| `/谱面统计 11451 jp` |
| `/谱面统计 11451 cn` |
