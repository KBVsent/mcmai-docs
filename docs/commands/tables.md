# 定数与表格

## 定数表

查询指定等级或定数的曲目定数表（图片形式）。

**指令：** `/定数表 <等级或定数> [服务器]`

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| 等级或定数 | 等级（如 `13`、`14+`）或定数范围 | `13+`、`14.0` |
| 服务器 | 查询区服（可选） | `cn`、`jp`、`intl` |

**示例：**

| 指令 |
|------|
| `/定数表 13+` |
| `/定数表 14` |
| `/定数表 14 jp` |

## 段位表

查询指定段位的课题曲目，并标注你在各曲目上的成绩。仅可查询自己。

**指令：** `/段位表 <段位名称> [服务器] [版本]`

**参数：**

| 参数 | 说明 |
|------|------|
| 段位名称 | 如 `真初段`、`真十段`、`真皆伝` 等 |
| 服务器 | 可选，`cn`、`jp`、`intl`（或 `国服`、`日服`、`国际服`），用于查看其他区服的段位表 |
| 版本 | 可选，查看往期版本的段位，默认为当前版本。可填牌子字（如 `鏡`、`丸`）或英文版本名（如 `prism`、`circle+`）；国服还可以填年份（如 `2025`、`舞萌DX2025`） |

服务器与版本不分先后。

**示例：**

| 指令 | 说明 |
|------|------|
| `/段位表 真十段` | 当前版本的真十段 |
| `/段位表 真皆伝 jp` | 日服当前版本的真皆伝 |
| `/段位表 真八段 jp 丸` | 日服 CiRCLE 版本的真八段 |
| `/段位表 真十段 cn 2025` | 国服舞萌DX 2025 的真十段 |

::: tip 可查询的版本
- **日服 / 国际服**：SPLASH PLUS（煌）及之后的版本。
- **国服**：舞萌DX 2023 及之后的版本，课题曲目为国服实际曲目，与日服同名版本不同。

输入的版本不可用时，Bot 会列出该区服可选的版本。
:::

::: tip 跨区服查表
服务器参数只决定查看哪个区服的段位，成绩始终来自你通过 `/切换服务器` 选定的区服。该区服有、而你所在区服尚未实装的谱面会标为「未实装」，与未游玩区分开。
:::

## 完成表

查询牌子/等级评价的完成进度表。

**指令：** `/完成表 <等级评价或牌子> [牌子评级] [服务器] [#用户名]`

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| 等级评价或牌子 | 数字等级（如 `13`、`14+`）或版本牌子字（如 `真`、`丸`） | `13+` |
| 牌子评级 | 牌子模式必填（`极`、`将`、`神`、`舞舞`） | `将` |
| 服务器 | 可选，查看其他区服的完成表（`cn`、`jp`、`intl`），可放在任意位置 | `jp` |
| #用户名 | 查询他人（需对方开启权限） | `#Sakura` |

牌子字和评级可以连写，例如 `/完成表 丸将`。

**示例：**

| 指令 |
|------|
| `/完成表 13` |
| `/完成表 14 #Sakura` |
| `/完成表 真 极` |
| `/完成表 丸将` |
| `/完成表 丸 将 #Sakura` |
| `/完成表 祭 将 jp` |

::: tip 跨区服查表
服务器参数只决定查看哪个区服的曲目表，成绩始终来自（被查询者）通过 `/切换服务器` 选定的区服。例如国服玩家发送 `/完成表 祭 将 jp`，看到的是日服的祭牌曲目，填入的是国服成绩。该区服有、而成绩所在区服尚未实装的谱面会标为「未实装」，与未游玩区分开。
:::

## 上分查询

查询当前 Rating 下，打哪些曲目可以提升 Rating。

**指令：** `/上分 <等级或定数> <分数> [页数]`

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| 等级或定数 | 目标等级或定数 | `14`、`13.7` |
| 分数 | 目标分值 | `10` |
| 页数 | 可选，分页查询 | `2` |

支持通过 `#用户名` 查询他人（需对方允许 B50 查询）。

**示例：**

| 指令 |
|------|
| `/上分 14 5` |
| `/上分 13.7 9 2` |

::: tip
结果图会区分两种加分：**Rating** 为达成该难度目标后游戏整体 Rating 提升的点数；**单曲 ra** 为该谱面单曲 ra 提升的点数（供已达成理论 Rating 的玩家参考）。
:::

::: tip 图中还包含
- **Rating 趋势**（仅日服 / 国际服）：结果图上方显示近 30 天的 Rating 净变化、上分局数与天数、单日与单局最高，以及标出每次上分涨幅的 Rating 曲线。查询他人时需对方允许分数查询，否则不显示这一块。
- **个性化推荐**：附上一张推荐的上分谱面，更多目标见下方的[上分目标推荐](#上分目标推荐)。
:::

### 新版本加分模式

查看本服最新版本新增的曲目中，哪些可以为你的 Rating 加分。该模式整图展示，不分页。

**指令：** `/上分 new`

只要参数中包含 `new` 即进入此模式，其余参数将被忽略。

### 上分目标推荐

根据你的成绩，为旧版本、新版本各推荐 3 个适合你的上分目标，标出目标评级、达成后的 Rating 增加量与推荐理由（如「距 SSS 差 0.20%」「同定数中偏简单」「谱型与个人倾向相符」）。

**指令：** `/上分 推荐`

只要参数中包含 `推荐` 即进入此模式，其余参数将被忽略。

::: tip
- 推荐按 Rating 增加量与相对难易排序，不代表一定能够达成。已建立[谱型倾向](/commands/analysis#谱型倾向)时会参考个人倾向，否则只按谱面难度修正。
- 需要有一定数量接近你水平的成绩才能给出推荐；成绩不足时，可以改用 `/上分 <等级> <分数>`，或发送 `/练习` 查看补测推荐。
:::
