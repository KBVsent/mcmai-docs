# 查歌搜索

## 歌名/别名/ID 查歌

通过歌曲名称、别名或 ID 搜索曲目。

**指令：** `/查歌 <关键词>`

**示例：**

| 指令 |
|------|
| `/查歌 潘多拉` |
| `/查歌 11451` |

---

## ID 精确查询

通过曲目 ID 查询详细谱面信息（难度、定数、谱师等）。

**指令：** `/id <歌曲ID>`

**示例：**

| 指令 |
|------|
| `/id 11451` |

::: tip 查歌与 /id 的结果
- **谱面结构**：显示一张高难度谱面的结构摘要（九维雷达、谱面内容难度数字、主要谱面标签与关联谱面）；Note 分布表在拟合定数旁列出各难度的结构定数。查看全部难度可点击「谱面分析」按钮或发送 `/谱面分析`，说明见[谱面分析与练习](/commands/analysis)。
- **同曲谱面**：结果中会列出同一首歌的其他谱面（标准谱、DX 谱、宴谱），各自带 ID 和等级，可用 `/id <ID>` 查看详情。不在你所在区服或已下架的谱面会单独标注。若还有另一张非宴谱的谱面，在支持按钮的平台上结果下方会多一个按钮，一键直达。
- **多个候选**：关键词匹配到多首曲目时，候选列表每条末尾会标注谱面类型 `[SD]` / `[DX]` / `[UTAGE]`，方便区分同名的标准谱与 DX 谱。
- **删除曲**：三个区服都找不到时，会继续在已从游戏中删除的曲目里查找，并提示该曲已删除、任何区服都无法游玩。查到的删除曲同样可以用 `/分数线` 查询。
:::

## 识曲（图片识别）

发送一张成绩图，自动识别其中的曲目并返回谱面详情，无需手动输入歌名。

**指令：** `/识曲`

**别名：** `识歌`

**用法：**

- 发送指令时**同时附带**一张成绩图；
- 或**引用**一条含成绩图的消息，再艾特 Bot 并发送指令。

识别成功后返回的内容与 `/查歌` 一致（谱面详情、谱面确认按钮等）。

::: tip 提高识别成功率
- 尽量发送**原图**：各平台发图默认会压缩，压缩后的截图容易识别失败。
- 图片需包含**完整的曲目标题面板**，否则会提示未能识别到标题。
- 若识别出标题却无法在曲库中唯一匹配，会返回识别到的标题文本，可据此改用 `/查歌` 查询。
:::

## 定数查歌

查找定数在指定范围内的曲目列表，支持分页。

::: tip 列表查歌的结果
定数、BPM、曲师、谱师、版本查歌的结果以两列卡片展示，每页 16 首：各难度定数一目了然，命中查询条件的难度与信息会高亮，版本显示为游戏 logo。结果超过一页时会附上 [McMai 曲库网站](https://mcmai-db.moev.cc) 的二维码，需要组合筛选与排序时可以直接前往。
:::

**指令：** `/定数查歌 <定数> [页数]`

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| 定数 | 单个定数或区间（`最小-最大`） | `13.7`、`14.0-14.7` |
| 页数 | 页码（可选，默认第 1 页） | `2` |

**示例：**

| 指令 |
|------|
| `/定数查歌 14.0` |
| `/定数查歌 13.7-14.0` |
| `/定数查歌 14.0 2` |

## BPM 查歌

查找 BPM 在指定范围内的曲目列表，支持分页。

**指令：** `/BPM查歌 <BPM值> [页数]`

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| BPM值 | 单个 BPM 或区间（`最小-最大`） | `180`、`160-200` |
| 页数 | 页码（可选，默认第 1 页） | `2` |

**示例：**

| 指令 |
|------|
| `/BPM查歌 180` |
| `/BPM查歌 160-200` |

## 版本查歌

按游戏版本或上线日期筛选曲目，支持分页。

**指令：** `/版本查歌 <版本关键词> [页数]`

**参数格式：**

| 输入 | 说明 | 示例 |
|------|------|------|
| `新版本` / `new` / `latest` | 本服最近一次更新加入的曲目 | `/版本查歌 新版本` |
| 日期 | 指定日期上线的曲目（`YYYYMMDD` 或 `YYYY-MM-DD`） | `/版本查歌 2025-01-09` |
| 牌子字 | 对应游戏版本的曲目 | `/版本查歌 丸`、`/版本查歌 鏡` |
| 版本名子串 | 版本名称关键字（大小写不敏感） | `/版本查歌 buddies`、`/版本查歌 2025` |

**示例：**

| 指令 |
|------|
| `/版本查歌 新版本` |
| `/版本查歌 2025-01-09` |
| `/版本查歌 丸` |
| `/版本查歌 prism 2` |

::: tip 跨服查询
若你所在区服没有所查询的版本，会自动从其他区服中查找该版本曲目并返回，结果上方会标注实际来源的区服。
:::
