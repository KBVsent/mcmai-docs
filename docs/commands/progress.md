# 进度查询

## 等级进度 / 牌子进度

查询指定等级或版本牌子下的达成进度或成绩统计，支持筛选和分页。

**指令：** `/进度 <等级或牌子> [评价/评级] [筛选] [页数]`

本指令有三种模式：等级加评价为**等级进度**，只填等级为**等级统计**，牌子字加评级为**牌子进度**。

### 等级进度模式

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| 等级 | `1`～`15`，可带 `+` | `13+` |
| 评价 | 评价名、FC / 同步评价或 DX 星级 | `SSS`、`fc`、`5star` |
| 已完成/未完成/未开始 | 可选，筛选完成状态 | `已完成`、`未完成`、`未开始` |
| 页数 | 可选，默认第 1 页 | `2` |

**分数评价对照：**

| 评价 | 达成率 |
|------|--------|
| `S` | ≥ 97.0000% |
| `S+` | ≥ 98.0000% |
| `SS` | ≥ 99.0000% |
| `SS+` | ≥ 99.5000% |
| `SSS` | ≥ 100.0000% |
| `SSS+` | = 101.0000% |

**同步/FC 评价：** `fc`、`fc+`、`ap`、`ap+`、`fs`、`fs+`、`fdx`、`fdx+`

**DX 星级评价：** `1star`～`7star`（如 `5star` 表示 DX 星级 ≥ 5 星；`7star` 为理论 DXScore 100%）

**示例：**

| 指令 |
|------|
| `/进度 13+ SSS` |
| `/进度 14 fc` |
| `/进度 14 5star` |
| `/进度 13+ SS 已完成` |
| `/进度 14 ap 未完成 2` |

::: tip 图中包含
完成率环与难度 × 定数的完成率矩阵；未完成的谱面会标出离目标还差多少。
:::

### 等级统计模式

不填评价时，显示该等级的成绩统计。

**格式：** `/进度 <等级> [已游玩/未游玩] [页数]`

统计包括游玩覆盖率与平均达成率，评级 / 连击 / 同步 / DX 星分布（未游玩的谱面也计入），以及每个难度 × 定数的游玩数与平均达成率。加上 `已游玩` 或 `未游玩` 可以翻页查看对应的谱面。

**示例：**

| 指令 | 说明 |
|------|------|
| `/进度 13+` | 13+ 的成绩统计 |
| `/进度 13+ 已游玩` | 查看 13+ 已游玩的谱面 |
| `/进度 13+ 未游玩 2` | 查看 13+ 未游玩的谱面，第 2 页 |

### 版本牌子进度模式

查询指定版本牌子的通关进度（如「丸将」「真极」等）。

**格式：** `/进度 <牌子字> <评级>`

| 评级 | 说明 |
|------|------|
| `极` | FC 所有曲目 |
| `将` | SSS 所有曲目 |
| `神` | AP 所有曲目 |
| `舞舞` | FDX 所有曲目 |

**示例：**

| 指令 |
|------|
| `/进度 丸 将` |
| `/进度 真 极` |
| `/进度 鏡 神 2` |

::: tip
牌子字和评级可以连写，例如 `/进度 丸将` 与 `/进度 丸 将` 效果相同。
:::

## 分类进度

按歌曲分类（动漫、东方 Project 等）查询进度或成绩统计。

**指令：** `/分类进度 <分类> [评价] [筛选] [页数]`

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| 分类 | 歌曲类别名称 | `动漫`、`东方`、`舞萌`、`V家`、`游戏`、`音击`、`宴` |
| 评价 | 可选，评价名或 FC / 同步评价；不填时显示该分类的成绩统计（与[等级统计模式](#等级统计模式)相同） | `SSS`、`fc`、`ap` |
| 筛选 | 可选。填了评价时为 `已完成`、`未完成`、`未开始`；不填评价时为 `已游玩`、`未游玩` | `已完成` |
| 页数 | 可选，默认第 1 页 | `2` |

**示例：**

| 指令 |
|------|
| `/分类进度 动漫 SSS` |
| `/分类进度 东方 SS 2` |
| `/分类进度 舞萌 fc 已完成 2` |
| `/分类进度 动漫` |
| `/分类进度 宴 已游玩` |

## 分数列表

查询你在指定等级/定数下所有曲目的分数列表，支持多维筛选与排序。

**指令：** `/分数列表 [等级或定数] [筛选条件...] [排序] [页数]`

**筛选条件（可叠加）：**

| 类型 | 可用值 |
|------|--------|
| Combo | `ap`、`ap+`/`app`、`fc`、`fc+`/`fcp`、`寸`（寸止） |
| Sync | `fs`、`fs+`/`fsp`、`fdx`、`fdx+`/`fdxp` |
| 评价 | `sss+`、`sss`、`ss+`、`ss`、`s+`、`s`、`a`、`aa`、`aaa`、`b`、`bb`、`bbb` 等 |
| 谱面类型 | `dx`、`sd` |
| 新旧版本 | `new`（新版）、`old`（旧版） |
| DX 星级 | `1star`～`7star`（`7star` = 理论 DXScore 100%） |
| 游戏版本 | 牌子字（如 `双`、`鏡`、`丸`）、版本英文别名（如 `buddies`、`prism`；DX 无印用 `deluxe`）或国服版本号（如 `舞萌DX2025`，也可只写年份 `2025`）；Plus 版本用 `+` 结尾，如 `buddies+` |

**运算符（仅 Combo / Sync / 评价可用）：**

| 写法 | 含义 |
|------|------|
| 直接写（如 `fc`、`sss`） | Combo / Sync 向上包含（`fc` 含 FC+、AP 等）；评价为精确匹配（`sss` 仅 SSS，不含 SSS+） |
| `=`（如 `=fc`） | 精确匹配，如 `=fc` 仅显示恰好 FC、未达到 FC+ 的曲目 |
| `>=` 或 `以上`（如 `>=s`、`s以上`） | 向上包含，如 `>=s` 显示 S 及以上的曲目 |

参数输入有误时，Bot 会指出是哪一个参数，并提示可能想输入的写法。结果图会标出本次的查询条件，并统计筛选结果的评级、连击、同步与 DX 星分布。

**排序：** `按X`（默认降序），或 `按X+`（升序）/ `按X-`（降序）

可排序字段：`ra`（Rating 贡献）、`达成度`/`acc`、`dx`（DX 分）、`定数`/`ds`

**示例：**

| 指令 | 说明 |
|------|------|
| `/分数列表 13+` | 查询所有 13+ 曲目分数 |
| `/分数列表 14 fc` | 筛选 FC（含 FC+）及以上 |
| `/分数列表 14 =fc` | 仅显示恰好 FC（未达 FC+）的曲目 |
| `/分数列表 14 ap 2` | 筛选 AP 及以上，第 2 页 |
| `/分数列表 14 dx sss` | 同时筛选 DX 谱和 SSS（不含 SSS+） |
| `/分数列表 14 dx >=sss` | 同时筛选 DX 谱和 SSS 及以上 |
| `/分数列表 s以上` | 筛选所有 S 及以上的成绩 |
| `/分数列表 14 按ra-` | 按 Rating 贡献降序排列 |
| `/分数列表 14 1star` | 筛选 DX 星级为 1 星的曲目 |
| `/分数列表 双` | 筛选 BUDDiES 版本曲目 |
| `/分数列表 buddies+` | 筛选 BUDDiES PLUS 版本曲目 |
| `/分数列表 舞萌DX2025` | 筛选国服舞萌DX 2025 版本曲目 |
