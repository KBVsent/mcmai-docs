# maimai 查分指南

McMai 是一款面向 maimai DX 玩家的免费查分 Bot。你可以在 QQ、LINE 或 Discord 更新并查询国服（CN）、日服（JP）和国际服（INTL）的游玩数据，无需打开独立查分网页。

## 可以查询哪些内容？

| 需求 | McMai 功能 | 详细说明 |
|------|------------|----------|
| 查看综合表现 | 生成 B50、B40 等上位成绩图 | [B50 查询与生成](/commands/b50) |
| 查询单曲成绩 | 查看达成率、DX 分与 FC/FS 状态 | [成绩查询](/commands/score) |
| 查找歌曲和谱面 | 按曲名、别名、曲师、BPM 或定数搜索 | [查歌搜索](/commands/search) |
| 追踪完成进度 | 查看等级、分类与完成表 | [进度查询](/commands/progress) |
| 比较玩家成绩 | 查看排行榜或使用好友 PK | [排行榜](/commands/leaderboard) |

## 支持的区服和更新方式

| 区服 | 数据更新方式 |
|------|--------------|
| 国服（CN） | 将舞萌｜中二公众号“玩家二维码”解析出的 `SGWCMAID` 内容发送给 Bot |
| 日服（JP） | 通过 `/绑定` 使用绑定页更新，或使用无需提交密码的书签更新方式 |
| 国际服（INTL） | 通过 `/绑定` 使用绑定页更新，或使用无需提交密码的书签更新方式 |

账号绑定、书签更新及区服切换的完整说明见[账号与服务器](/commands/account)。

## 开始查分

1. 在 QQ、LINE 或 Discord 添加并打开 McMai。
2. 按照所在区服完成一次数据更新。
3. 使用 `/切换服务器 cn`、`/切换服务器 jp` 或 `/切换服务器 intl` 选择区服。
4. 发送 `/b50` 查看上位成绩，或发送 `/info <曲目ID或曲名>` 查询单曲成绩。

如果你还没有添加 Bot，请先阅读[快速开始](/guide/getting-started)；需要查找其他功能和参数时，请打开[指令参考](/commands/basic)。

::: info 隐私提示
日服和国际服玩家也可以选择书签方式更新成绩，无需向 McMai 提交 SEGA ID 和密码。
:::
