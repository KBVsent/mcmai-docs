# QQ Bot 使用小提示

McMai 在 QQ 平台上以 QQ Bot 形式运行，以下是一些实用技巧，帮助你更高效地使用指令。

## 使用 `/` 触发指令菜单

在聊天框中直接输入 `/`，即可唤出 Bot 的指令菜单，快速浏览所有可用指令。

你也可以在 `/` 后继续输入关键词来**筛选指令**，例如输入 `/群排行` 即可快速定位到排行相关的指令。

<img src="/QQbot_Tips_1.jpg" alt="输入 / 触发指令菜单" style="max-width: 360px;" />

## `/c` 通用前缀

`/c` 是**通用指令前缀**，在群聊中使用时无需手动 @ Bot。

在聊天框中输入 `/c`，从弹出的指令列表中选择 `/c` 这条指令，再继续输入你想要使用的指令和参数

例如：

```
/c 指令名 参数
```

例如，查询歌曲排行：

<img src="/QQbot_Tips_2.jpg" alt="使用 /c 前缀发送指令" style="max-width: 480px;" />

::: tip 小结
- 输入 `/` → 触发指令菜单，支持关键词筛选
- 输入 `/c` → 触发指令菜单，选中 `/c` 指令 → 继续输入`指令`和`参数` → 快速触发不在快捷菜单中的指令
:::

## 兼容模式

如果 Bot 的消息提示版本过低、显示异常，或无法点击预览图片（多见于旧版 QQ 客户端或 TIM），可发送 `/兼容模式` 切换为传统消息：消息以纯文本形式发送，不再使用 markdown 与按钮。再次发送即可关闭。

**别名：** `兼容`、`compat`
