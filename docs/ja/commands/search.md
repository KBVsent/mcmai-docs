# 楽曲検索

## 曲名 / 別名 / ID で検索

曲名・別名・ID で楽曲を検索します。

**コマンド：** `/曲検索 <キーワード>`

**例：**

| コマンド |
|---------|
| `/曲検索 潘多拉` |
| `/曲検索 11451` |

---

## ID 精密検索

ID を使って詳細な譜面情報（難易度・定数・譜面製作者など）を照会します。

**コマンド：** `/id <曲 ID>`

**例：**

| コマンド |
|---------|
| `/id 11451` |

::: tip 曲検索と /id の結果
- **譜面構造**：高難易度の譜面 1 つについて構造の要約（9 軸レーダー・構造定数・主な譜面タグ・関連譜面）を表示します。ノーツ分布表では、各難易度の構造定数がフィット定数の横に並びます。全難易度を見るには「譜面分析」ボタンを押すか `/譜面分析` を送信してください。詳しくは[譜面分析と練習](/ja/commands/analysis)を参照してください。
- **同曲の譜面**：同じ曲の他の譜面（STD 譜面・DX 譜面・宴譜面）が ID とレベル付きで一覧表示されます。詳細は `/id <ID>` で確認できます。あなたのサーバーにない譜面や削除済みの譜面にはその旨が表示されます。宴以外の別譜面がある場合、ボタン対応のプラットフォームでは結果の下にその譜面へ直接移動できるボタンが表示されます。
- **候補が複数の場合**：キーワードに複数の楽曲が一致すると、候補一覧の各行末に譜面タイプ `[SD]` / `[DX]` / `[UTAGE]` が表示され、同名の STD 譜面と DX 譜面を区別できます。
- **削除曲**：どのサーバーにも見つからない場合は、ゲームから削除された楽曲も検索し、どのサーバーでもプレイできない旨を表示します。見つかった削除曲は `/ボーダー` にも対応しています。
:::

## 曲認識（画像から検索）

リザルト画像を送ると、その中の楽曲を自動で認識して譜面詳細を返します。曲名を入力する必要はありません。

**コマンド：** `/曲認識`

**使い方：**

- コマンドと**一緒に**リザルト画像を添付する；または
- リザルト画像を含むメッセージに**返信**し、Bot をメンションしてコマンドを送信する。

認識に成功すると、`/曲検索` と同じ内容（譜面詳細・譜面確認ボタンなど）が返されます。

::: tip 認識精度を上げるには
- できるだけ**元画像（オリジナル）**を送信してください。各プラットフォームは既定で画像を圧縮するため、圧縮後のスクリーンショットは認識に失敗しやすくなります。
- 画像には**曲名パネル全体**が写っている必要があります。写っていない場合はタイトルを認識できなかったと表示されます。
- タイトルは認識できたが楽曲を一意に特定できない場合、認識したタイトル文字列が返されるので、それを使って `/曲検索` で調べられます。
:::

## 定数で検索

指定した定数の範囲内にある楽曲一覧を表示します（ページング対応）。

::: tip 一覧検索の結果
定数・BPM・アーティスト・譜面製作者・バージョン検索の結果は 2 列のカードで 1 ページ 16 曲表示されます。各難易度の定数が一目で分かり、検索条件に一致した難易度や情報はハイライトされ、バージョンはゲームのロゴで表示されます。結果が 1 ページを超える場合は [McMai 楽曲データベースサイト](https://mcmai-db.moev.cc) の QR コードが付き、フィルターや並べ替えを組み合わせたいときはそちらを利用できます。
:::

**コマンド：** `/定数検索 <定数> [ページ]`

| パラメーター | 説明 | 例 |
|------------|------|----|
| 定数 | 単一値または範囲（`最小-最大`） | `13.7`、`14.0-14.7` |
| ページ | ページ番号（任意、デフォルト 1） | `2` |

**例：**

| コマンド |
|---------|
| `/定数検索 14.0` |
| `/定数検索 13.7-14.0` |
| `/定数検索 14.0 2` |

## BPM で検索

指定した BPM 範囲内の楽曲一覧を表示します（ページング対応）。

**コマンド：** `/BPM検索 <BPM> [ページ]`

| パラメーター | 説明 | 例 |
|------------|------|----|
| BPM | 単一値または範囲（`最小-最大`） | `180`、`160-200` |
| ページ | ページ番号（任意、デフォルト 1） | `2` |

**例：**

| コマンド |
|---------|
| `/BPM検索 180` |
| `/BPM検索 160-200` |

**コマンド：** `/アーティスト検索 <作曲者名> [ページ]`

**例：**

| コマンド |

## バージョン検索

ゲームバージョンまたはリリース日で楽曲を絞り込みます（ページング対応）。

**コマンド：** `/バージョン検索 <バージョンキーワード> [ページ]`

| 入力形式 | 説明 | 例 |
|---------|------|----|
| `new` / `latest` | 自サーバーの最新アップデートで追加された楽曲 | `/バージョン検索 new` |
| 日付 | 指定日にリリースされた楽曲（`YYYYMMDD` または `YYYY-MM-DD`） | `/バージョン検索 2025-01-09` |
| プレート文字 | 対応するゲームバージョンの楽曲 | `/バージョン検索 丸`、`/バージョン検索 鏡` |
| バージョン名部分文字列 | バージョン名のキーワード（大文字・小文字不問） | `/バージョン検索 buddies`、`/バージョン検索 2025` |

**例：**

| コマンド |
|---------|
| `/バージョン検索 new` |
| `/バージョン検索 2025-01-09` |
| `/バージョン検索 丸` |
| `/バージョン検索 prism 2` |

::: tip サーバー横断検索
お使いのサーバーに該当バージョンがない場合は、自動的に他サーバーから該当バージョンの楽曲を検索して返します。結果の上部に実際の取得元サーバーが表示されます。
:::
