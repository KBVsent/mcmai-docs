# 譜面分析と練習

McMai は各譜面の構造を分析し、あなたのスコアと組み合わせて譜面傾向・練習おすすめ・[レート上げ目標](/ja/commands/tables#rating-targets)を提示します。

## 譜面構造

曲検索・譜面分析・練習おすすめなどの結果画像では、次の用語を使います。

| 用語 | 説明 |
|------|------|
| 9 軸 | 譜面を 9 つの観点で表します：手の速さ、体力、広範囲移動、両手の分担、スライド精度、スライド認識、タッチ操作、リズム認識、視覚認識。全譜面を基準に算出し、レーダーで表示します |
| 構造定数 | 譜面の内容から算出した定数で、レーダーの中央に表示されます。譜面内容そのものの難しさのみを表し、個人差などの要素は含みません。曲検索のノーツ分布表ではフィット定数の横に並び、フィット定数がない楽曲は構造定数のみ表示されます |
| 譜面タグ | 譜面に含まれる配置（縦連、トリルなど）で、譜面内で占める時間の長い順に並びます |
| 関連譜面 | 構造が近いほかの譜面 |

---

## 譜面分析

1 曲の全難易度の譜面構造を 1 枚の画像にまとめて表示します。スコアの連携は不要です。

**コマンド：** `/譜面分析 <曲 ID または曲名>`

**例：**

| コマンド |
|---------|
| `/譜面分析 11451` |
| `/譜面分析 系ぎて` |

::: tip
画像の下部には、その曲の主な配置を練習するコマンド（例：`/練習 縦連`）が表示されます。ボタン対応のプラットフォームでは「練習」ボタンも使えます。`/曲検索` の結果にある「譜面分析」ボタンからもこの画像を開けます。
:::

## 練習おすすめ

あなたの譜面傾向に合わせて練習用の譜面を推薦し、各譜面の 9 軸構造と現在のスコアを表示します。推薦は毎日入れ替わります。照会できるのは自分のみです。

**コマンド：** `/練習 [能力または配置] [難易度の範囲]`

**パラメーター：**

| パラメーター | 説明 | 例 |
|------------|------|----|
| 能力または配置 | 任意。能力は 9 軸のいずれか、配置は `/info` や `/譜面分析` に表示される譜面タグです。省略すると相対的に苦手寄りの 2 項目を練習します | `手の速さ`、`縦連` |
| 難易度の範囲 | 任意。レベルまたは定数を `-` でつなぎます。1 つだけ書くとそのレベルのみ。省略するとスコアから推定します | `12-13`、`13`、`13.5-14.0` |

能力・配置と範囲の順番は問いません。小数点のない数字はレベルとして扱われ、例えば `12-13` は 12・12+・13 の各レベルを指します。

**例：**

| コマンド | 説明 |
|---------|------|
| `/練習` | 苦手寄りの項目に合わせて推薦 |
| `/練習 手の速さ` | 手の速さのみ |
| `/練習 縦連 13` | レベル 13 の縦連を含む譜面 |
| `/練習 12-13` | レベル 12〜13 から推薦 |

::: tip スコア連携なしでも使える
配置を指定した練習（例：`/練習 縦連`）や、難易度の範囲を指定した場合は、スコアの連携は不要です。新規プレイヤーも利用できます。
:::

::: tip 補完おすすめ
譜面傾向の算出には十分なスコアのサンプルが必要です。足りない間、`/練習` は「補完用譜面」を推薦します。プレイしてスコアを更新し、サンプルが揃うと B50 に譜面傾向が表示され、このコマンドも練習おすすめに切り替わります。補完用譜面はサンプル補充のためのもので、得意・不得意を示すものではありません。
:::

## 譜面傾向

スコアが十分にあると、B50 画像の分析エリアに譜面傾向のレーダーが表示されます。大きさは総合レベル、形は譜面タイプごとの相対的な成績を表し、苦手寄りの項目が示されます。

- あなた自身のベストスコアだけから算出します（B50 に限らず利用できるすべてのスコア）。比べるのは自分の中での譜面タイプ間の成績で、他のプレイヤーとの比較ではありません。
- 示すのは苦手寄りの項目のみで、得意な項目は示しません。タッチ操作は評価の対象外です。
- サンプルが足りない場合は表示されません。`/練習` で補完用譜面を確認できます。
- 確立した譜面傾向は、`/練習` と [`/レート上げ おすすめ`](/ja/commands/tables#rating-targets) の並び順、[`/今日のmaimai`](/ja/commands/basic#今日の運勢) のおすすめ譜面に使われます。
