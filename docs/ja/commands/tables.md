# 譜面定数表

## 定数表

指定したレベルまたは定数の定数表（画像形式）を照会します。

**コマンド：** `/定数表 <レベルまたは定数> [サーバー]`

| パラメーター | 説明 | 例 |
|------------|------|----|
| レベルまたは定数 | レベル（`13`、`14+`）または定数範囲 | `13+`、`14.0` |
| サーバー | 照会サーバー（任意） | `cn`、`jp`、`intl` |

**例：**

| コマンド |
|---------|
| `/定数表 13+` |
| `/定数表 14` |
| `/定数表 14 jp` |

## 段位表

指定した段位の課題曲と、各曲でのあなたのスコアを照会します。照会できるのは自分のみです。

**コマンド：** `/段位表 <段位名> [サーバー] [バージョン]`

| パラメーター | 説明 |
|------------|------|
| 段位名 | 例：`真初段`、`真十段`、`真皆伝` |
| サーバー | 任意。`cn`、`jp`、`intl`（または `日服` など）。他サーバーの段位表を表示 |
| バージョン | 任意。過去バージョンの段位を表示（デフォルトは現行バージョン）。称号の漢字（`鏡`、`丸` など）または英語のバージョン名（`prism`、`circle+` など）で指定 |

サーバーとバージョンの順番は問いません。

**例：**

| コマンド | 説明 |
|---------|------|
| `/段位表 真十段` | 現行バージョンの真十段 |
| `/段位表 真皆伝 jp` | 日本版・現行バージョンの真皆伝 |
| `/段位表 真八段 jp 丸` | 日本版 CiRCLE の真八段 |

::: tip 照会できるバージョン
- **日本版 / 国際版**：SPLASH PLUS（煌）以降。
- **中国版**：舞萌DX 2023 以降。課題曲は中国版の実際の楽曲で、日本版の同名バージョンとは異なります。

指定したバージョンが利用できない場合は、そのサーバーで選べるバージョンが表示されます。
:::

::: tip 他サーバーの表を見る
サーバー指定で切り替わるのは表示する段位のみです。スコアは常に `/鯖変更` で選んだサーバーのものが使われます。そのサーバーにはあってもあなたのサーバーでは未実装の譜面は「未実装」と表示され、未プレイとは区別されます。
:::

## コンプリート表

グレード評価またはプレートのコンプリート進捗を照会します。

**コマンド：** `/プレート進捗 <グレードまたはプレート> [プレートレベル] [サーバー] [#ユーザー名]`

**パラメーター：**

| パラメーター | 説明 | 例 |
|------------|------|----|
| グレードまたはプレート | 数字レベル（`13`、`14+`）またはバージョンプレート文字（`真`、`丸`） | `13+` |
| プレートレベル | プレートモード必須（`極`、`將`、`神`、`舞舞`） | `將` |
| サーバー | 任意。他サーバーの表を表示（`cn`、`jp`、`intl`）。引数のどこに置いても可 | `cn` |
| #ユーザー名 | 他のプレイヤーを照会（相手の許可が必要） | `#Sakura` |

プレート文字とレベルは連結して入力できます。例：`/プレート進捗 丸將`。

**例：**

| コマンド |
|---------|
| `/プレート進捗 13` |
| `/プレート進捗 14 #Sakura` |
| `/プレート進捗 真 極` |
| `/プレート進捗 丸將` |
| `/プレート進捗 丸 將 #Sakura` |
| `/プレート進捗 祭 將 cn` |

::: tip 他サーバーの表を見る
サーバー指定で切り替わるのは表示する楽曲のみです。スコアは常に（照会対象のプレイヤーが）`/鯖変更` で選んだサーバーのものが使われます。例えば日本版のプレイヤーが `/プレート進捗 祭 將 cn` を送ると、中国版の祭プレート対象曲に日本版のスコアが表示されます。そのサーバーにはあってもスコア側のサーバーでは未実装の譜面は「未実装」と表示され、未プレイとは区別されます。
:::

## Rating 向上クエリ

現在の Rating を上げるためにプレイすべき楽曲を照会します。

**コマンド：** `/レート上げ <レベルまたは定数> <スコア> [ページ]`

| パラメーター | 説明 | 例 |
|------------|------|----|
| レベルまたは定数 | 目標レベルまたは定数 | `14`、`13.7` |
| スコア | 目標スコア値 | `10` |
| ページ | 任意、ページング | `2` |

`#ユーザー名` を付けると他のプレイヤーを照会できます（相手が B50 閲覧を許可している必要があります）。

**例：**

| コマンド |
|---------|
| `/レート上げ 14 5` |
| `/レート上げ 13.7 9 2` |

::: tip
結果画像は 2 種類の加点を区別します：**Rating** はその難易度の目標達成時にゲーム全体の Rating が上がる点数、**単曲 ra** はその譜面の単曲 ra が上がる点数（理論 Rating に到達したプレイヤー向け）です。
:::

::: tip 画像に含まれるその他の内容
- **Rating の推移**（日本版 / 国際版のみ）：画像上部に直近 30 日の Rating の純増減、レート上昇のプレイ数と日数、1 日・1 プレイあたりの最高上昇量、上昇ごとの幅を記した Rating グラフを表示します。他のプレイヤーを照会する場合、相手がスコア閲覧を許可していなければこの部分は表示されません。
- **個人向けおすすめ**：おすすめのレート上げ譜面を 1 つ表示します。もっと見るには下の[レート上げ目標](#rating-targets)を利用してください。
:::

### 新バージョン加点モード

お使いのサーバーの最新バージョンで追加された楽曲のうち、Rating を上げられる楽曲を表示します。このモードは 1 枚の画像で表示され、ページングはありません。

**コマンド：** `/レート上げ new`

引数のどこかに `new` を含めるとこのモードに入ります。その他の引数は無視されます。

### レート上げ目標 {#rating-targets}

あなたのスコアをもとに、旧バージョン・新バージョンからそれぞれ 3 つずつレート上げの目標を推薦し、目標評価、達成時の Rating 上昇量、推薦理由（例：「SSS まで 0.20%」「同じ定数の中では易しめ」「譜面傾向に合う」）を表示します。

**コマンド：** `/レート上げ おすすめ`

引数のどこかに `おすすめ` を含めるとこのモードに入ります。その他の引数は無視されます。

::: tip
- 推薦は Rating 上昇量と相対的な難しさで並べたもので、達成を保証するものではありません。[譜面傾向](/ja/commands/analysis#譜面傾向)が確立していれば個人の傾向も考慮し、そうでなければ譜面の難しさのみで補正します。
- 推薦には、あなたのレベルに近いスコアがある程度必要です。足りない場合は `/レート上げ <レベル> <スコア>` を使うか、`/練習` で補完用譜面を確認してください。
:::
