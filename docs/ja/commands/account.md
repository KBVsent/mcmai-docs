# アカウントとサーバー

## アカウント連携

**コマンド：** `/連携`

**説明：** 専用の連携リンク（または QR コード）が生成されます。ブラウザで開き、サーバーを選んでページの案内に従って連携を完了してください。

| サーバー | 方法 |
|---------|------|
| JP / INTL | SEGA ID を連携、または[ブックマークレット](/ja/guide/bookmarklet-update)で更新 |
| CN | [NET WeChat 認証](/ja/guide/cn-net-update)を設定、または [MAID を送信](#maid) |

::: warning 注意
`/連携` を実行するたびに新しい認証コードが生成されます。速やかに連携を完了してください。
:::

---

## ブックマークレットで成績を更新

日本版と国際版では、ブラウザのログイン済み NET セッションを使ってスコアを更新できます。SEGA ID とパスワードを McMai に送信する必要はありません。

`/連携` を送信し、連携ページで地域とブックマークレット方式を選んで発行・登録します。登録後はログイン済みの maimai NET ページで実行します。

[ブックマークレット更新ガイド](/ja/guide/bookmarklet-update)に、パソコンの Chrome、iPhone の Safari、Android の Chrome の図解を掲載しています。

コードにはアップロード用の認証情報が含まれます。再発行すると以前のコードは直ちに無効になります。

## 中国版 MAID による更新 {#maid}

Bot への個別メッセージ、またはグループで Bot をメンションして MAID（`SGWCMAID` で始まる 84 文字の文字列）を送信すると、中国版のスコアが更新されます。[PC50](/ja/commands/b50#pc50) に使うプレイ回数は MAID による更新でのみ取得されます。

::: details MAID の取得方法
1. WeChat で「舞萌 | 中二」公式アカウントを開く
2. 「获取二维码」（QR コード取得）をタップ
3. QR コードページが表示される
4. QR コードを長押しでスキャンし、表示される `SGWCMAID` 文字列をコピーする
:::

## マルチプラットフォーム間のデータ共有

同じゲームアカウント（同じカード）を複数のプラットフォームで連携すると、データは自動的に共有されます。**いずれか 1 つのプラットフォームでスコアを更新すれば、他のプラットフォームにも反映される**ため、プラットフォームごとに更新する必要はありません。

::: tip ヒント
共有の判定単位はゲームアカウントであり、プラットフォーム上の身元ではありません。異なるカードを連携したアカウントはそれぞれ独立し、共有されません。
:::

## アカウント連携解除

現在の SEGA アカウント連携を解除し、**全サーバー**のスコア記録を削除します。

**コマンド：** `/連携解除 [確認]`

::: danger 取り消せません
連携解除は以下を一括で削除し、**復元できません**：

- SEGA アカウント連携情報（segaid・パスワード）
- 全サーバー（CN / JP / INTL）のスコア記録

誤操作防止のため二段階確認が必要です：まず `/連携解除` を送信して削除内容を確認し、次に `/連携解除 確認` を送信して実行します。確認リクエストは **5 分間** 有効で、過ぎた場合は再度やり直してください。
:::

**例：**

| コマンド | 説明 |
|---------|------|
| `/連携解除` | 削除内容を確認し、解除リクエストを開始 |
| `/連携解除 確認` | 確認して解除を実行（5 分以内有効） |

## Aime カード切り替え

日本サーバーアカウントの Aime カードスロットを確認・切り替えます。

::: info 日本サーバー専用
この機能は、日本サーバーアカウントを連携済みの日本サーバー（JP）ユーザーのみ利用できます。
:::

**コマンド：** `/aime [カード番号]`

**エイリアス：** `カード選択`

**説明：**

- `/aime`：アカウント内のすべての Aime カードを一覧表示し、現在選択中のカードを Rating・カード種別（標準カード / 無料カード）とともに表示します。
- `/aime <番号>`：指定した番号のカードに切り替えます。
- アカウント内にカードが 1 枚のみの場合は切り替え不要です。

切り替えは次回 `/データ更新` を実行した時に反映されます。

**例：**

| コマンド | 説明 |
|---------|------|
| `/aime` | アカウント内のすべての Aime カードを表示 |
| `/aime 2` | 2 枚目のカードに切り替え |

## ユーザー名設定

`#ユーザー名` で他のユーザーがあなたのデータを照会しやすくするユーザー名を設定します。

**コマンド：** `/ユーザー名設定 [ユーザー名|クリア]`

**例：**

| コマンド | 説明 |
|---------|------|
| `/ユーザー名設定 Sakura` | ユーザー名を Sakura に設定 |
| `/ユーザー名設定` | 現在のユーザー名を確認（未設定時は照会 ID を表示） |
| `/ユーザー名設定 クリア` | ユーザー名をクリア |

**ユーザー名のルール：** 漢字・ひらがな・カタカナ・英数字が使えます（数字のみは不可）。10 文字以内です。半角カタカナや全角英数字は自動で変換されます。既存のユーザー名と見分けにくい名前は設定できません。

**照会 ID：**

すべてのユーザーにはシステムが自動付与する**照会 ID**（`#mc` 始まりの短い ID）があります。ユーザー名を設定していなくても、この ID で他のユーザーから照会してもらえます。ユーザー名を設定後は `#ユーザー名` と照会 ID のどちらでも使えます。

::: warning 注意
ユーザー名をクエリパラメーターとして使用する際は、必ず `#` を先頭に付けてください。

例：`/b50 #Sakura`（`/b50 Sakura` ではありません）
:::

::: tip 審査について
ユーザー名は設定後に審査が行われます：

- **審査中**：`#ユーザー名` で照会は可能ですが、表示時にユーザー名が一部マスクされます
- **審査通過**：ユーザー名が完全表示されます
- **審査不合格**：ユーザー名は自動削除されます。再設定が必要です

ユーザー名は **3 日間に 1 回** しか変更できないため、慎重に設定してください。
:::

## プライバシー設定

他のユーザーがあなたのゲームデータを照会できるかどうかを制御します。

**コマンド：** `/公開設定 <アクション> [対象]`

**アクション：**

| アクション | 説明 |
|-----------|------|
| `状態` | 現在のプライバシー設定を確認 |
| `オン` | 指定対象の照会を許可 |
| `off` | 指定対象の照会を拒否 |
| `リセット` | 指定対象をデフォルト（全許可）にリセット |

**対象：**

| 対象 | 説明 |
|------|------|
| `閲覧` | マスタースイッチ — すべての照会権限を制御 |
| `b50閲覧` | Best 50 などの各種 50 系照会、PK・レート上げの照会 |
| `スコア閲覧` | スコア（info）・プレイ履歴・レート推移の照会 |
| `進捗閲覧` | コンプリート表・進捗・ジャンル進捗・スコアリストの照会 |

::: tip
`閲覧`（マスタースイッチ）を無効にすると、他のユーザーはあなたのデータを一切照会できなくなります。個別設定より優先されます。ランキングは公開設定の対象外です。
:::

**例：**

| コマンド | 説明 |
|---------|------|
| `/公開設定 状態` | 現在のプライバシー状況を確認 |
| `/公開設定 off 閲覧` | 他ユーザーによるすべての照会を拒否 |
| `/公開設定 off スコア閲覧` | スコア照会のみを拒否 |
| `/公開設定 オン b50閲覧` | Best 50 照会を再び許可 |
| `/公開設定 リセット` | すべての照会権限をデフォルトにリセット |

## フレンド管理

McMai のフレンドリストを管理します（PK 機能で使用）。

**コマンド：** `/フレンド [アクション] [パラメーター]`

**アクション：**

| アクション | 説明 | パラメーター |
|-----------|------|------------|
| `リスト` | フレンドリストを表示 | — |
| `追加` | フレンドを追加 | `#ユーザー名` |
| `削除` | フレンドを削除 | `#ユーザー名` またはスロット番号 |

**例：**

| コマンド | 説明 |
|---------|------|
| `/フレンド リスト` | フレンドリストを表示 |
| `/フレンド 追加 #Sakura` | Sakura というフレンドを追加 |
| `/フレンド 追加 #Sakura 1` | スロット 1 に Sakura を追加 |
| `/フレンド 削除 1` | スロット 1 のフレンドを削除 |
