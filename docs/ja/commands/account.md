# アカウントとサーバー

## アカウント連携 {#bind}

**コマンド：** `/連携`

**説明：** 専用の連携リンクが生成されます。ブラウザで開き、サーバーを選んでページの案内に従って連携を完了してください。SEGA ID を連携するか LXNS を許可すると、その場でスコアが一度更新されます。チェックを入れれば、McMai の現在のサーバーも同時に切り替えられます。

連携リンクは、本人だけが見られる場所にのみ送られます：個別チャット、QQ グループ内の本人だけが押せるボタン、Discord の `/bind` スラッシュコマンドの非公開返信です。それ以外のグループチャットでは、Bot から個別チャットで `/連携` を送るよう案内されます。

| サーバー | 方法 |
|---------|------|
| 日本版 | SEGA ID を連携、または[ブックマークレット](/ja/guide/bookmarklet-update)で更新 |
| インターナショナル版 | SEGA ID を連携、[ログイントークン](#intl-token)を登録、または[ブックマークレット](/ja/guide/bookmarklet-update)で更新 |
| 中国版 | [NET WeChat 認証](/ja/guide/cn-net-update)を設定、[MAID を送信](#maid)、または [LXNS](#lxns) を許可 |

どのサーバーでも、[カスタムデータソース](/ja/guide/custom-data-source)からスコアファイルをアップロードできます。

::: warning 注意
連携リンクの有効期限は 10 分です。`/連携` を実行するたびに新しいリンクが生成されます。他人には共有しないでください。
:::

::: tip 連携済みアカウントの管理
連携ページには、各サーバーで関連付けられたゲームアカウントが一覧表示されます。選ぶと現在使用するアカウントを切り替えられます（[`/カード選択`](#aime) と同じ効果）。不要になったアカウントは、連携ページで個別に連携解除できます。関連付けを外してもスコアデータは残り、あとで同じアカウントでもう一度更新すれば再び関連付けられます。パスワードまたは LXNS で更新していたアカウントを連携解除すると、保存済みのパスワードや LXNS の許可も一緒に削除される場合があります。具体的な影響は確認ダイアログに表示されます。
:::

## インターナショナル版のログイントークン {#intl-token}

X・Facebook・LINE で maimai DX NET にログインしていて、SEGA ID のパスワードを持っていないインターナショナル版プレイヤーは、代わりにログイントークンで連携できます。連携後は同じく `/データ更新` を使えます。

`/連携` を送信し、連携ページで「海外版」→「トークン」を選んで、`clal` を含む cookie を貼り付けます。取得方法は、入力欄の横にある「取り出し方を ChatGPT に聞く」から、お使いの端末に合わせて質問できます。

::: warning ログアウトするとトークンは無効になります
どの端末でも maimai DX NET からログアウトするとトークンは無効になり、再登録が必要です。トークンはログイン情報と同じ扱いのため、他人に渡さないでください。
:::

## ブックマークレットで成績を更新

日本版とインターナショナル版では、ブラウザのログイン済み NET セッションを使ってスコアを更新できます。SEGA ID とパスワードを McMai に送信する必要はありません。

`/連携` を送信し、連携ページで地域と「ブックマーク」方式を選び、ブックマークレットを発行・登録します。登録後はログイン済みの maimai NET ページで実行します。

[ブックマークレット更新ガイド](/ja/guide/bookmarklet-update)に、パソコンの Chrome、iPhone の Safari、Android の Chrome の図解を掲載しています。

コードにはアップロード用の認証情報が含まれます。再発行すると以前のコードは直ちに無効になります。

## 中国版 MAID による更新 {#maid}

Bot への個別メッセージ、またはグループで Bot をメンションして MAID（`SGWCMAID` で始まる 84 文字の文字列）を送信するか、連携ページの「中国版」→「MAID」に貼り付けると、中国版のスコアが更新されます。中国版の [PC50](/ja/commands/b50#pc50) に使うプレイ回数は MAID による更新でのみ取得されます。

::: details MAID の取得方法
1. WeChat で「舞萌 | 中二」公式アカウントを開く
2. 「获取二维码」（QR コード取得）をタップ
3. QR コードページが表示される
4. QR コードを長押しでスキャンし、表示される `SGWCMAID` 文字列をコピーする
:::

## LXNS（落雪查分器） {#lxns}

中国版プレイヤーは LXNS（落雪查分器）を許可すると、LXNS 上のスコアで B50 などの照会機能を使えます。`/連携` を送信し、連携ページで「中国版」→「LXNS」を選び、「LXNS で許可する」を押して許可します。

- 自分のスコアを照会すると、LXNS 上の新しいスコアが自動で同期されます。`/データ更新` を送信すればすぐに同期できます。
- LXNS のアカウントは中国版のほかのアカウントと並んで表示され、[`/カード選択`](#aime) または連携ページで切り替えられます。
- LXNS のデータにはプレイ履歴とプレイ回数が含まれないため、`/プレイ履歴`・`/レート推移`・`/pc50` は使えません。
- LXNS のデータはデフォルトではランキングに含まれません。`/グルラン` と `/グループレート` に [`all` パラメーター](/ja/commands/leaderboard#group-song-rank)を付けると、あわせて表示できます。

許可が無効になった場合は、Bot から `/連携` で再度許可するよう案内されます。同期済みのスコアは残ります。

## マルチプラットフォーム間のデータ共有

同じゲームアカウント（同じカード）を複数のプラットフォームで連携すると、データは自動的に共有されます。**いずれか 1 つのプラットフォームでスコアを更新すれば、他のプラットフォームにも反映される**ため、プラットフォームごとに更新する必要はありません。

::: tip ヒント
共有の判定単位はゲームアカウントであり、プラットフォーム上の身元ではありません。異なるカードを連携したアカウントはそれぞれ独立し、共有されません。
:::

## スコア照会時の自動更新 {#auto-update}

自分のスコアを照会したとき、データが 1 時間以上更新されていなければ、Bot が先に更新してから結果を表示します。LXNS は 1 時間の制限を受けず、照会時に新しいスコアがあれば同期されます。

**コマンド：** `/自動更新 [オン|オフ]`

- パラメーターなし：現在の状態を確認します。デフォルトはオンです。
- 対象は SEGA アカウント（日本版・インターナショナル版）、インターナショナル版のログイントークン、LXNS で連携したデータです。ブックマークレット、中国版の NET と MAID、カスタムデータソースのデータは、それぞれの方法で手動更新してください。
- 自分を照会したときのみ動作し、他のプレイヤーを照会しても相手のデータは更新されません。楽曲検索と今日の運勢では動作しません。
- 日本版・インターナショナル版では、`/プレイ履歴` と `/レート推移` を表示するときも自動更新されます。

**例：**

| コマンド | 説明 |
|---------|------|
| `/自動更新` | 現在の状態を確認 |
| `/自動更新 オフ` | オフにする。以降は必要なときに `/データ更新` で手動更新 |
| `/自動更新 オン` | 再びオンにする |

::: warning 更新中は NET にログインしないでください
SEGA アカウントまたはログイントークンで更新するとき（自動更新を含む）は、順番待ちと更新の間、maimai DX NET に手動でログインしないでください。更新完了後もプレイ履歴をバックグラウンドで取得し続けるため、その後の数分間も同様にログインしないでください。
:::

## アカウント削除

すべてのログイン情報とスコア記録を削除します。

**コマンド：** `/アカウント削除 [確認]`

::: danger 取り消せません
アカウント削除は以下を一括で削除し、**復元できません**：

- SEGA アカウントのログイン情報（SEGA ID・パスワード、またはログイントークン）
- LXNS の許可、カスタムデータソースのアップロードトークン
- 全サーバーのスコア記録

誤操作防止のため二段階確認が必要です：まず `/アカウント削除` を送信して削除内容を確認し、次に `/アカウント削除 確認` を送信して実行します。確認リクエストは **5 分間** 有効で、過ぎた場合は再度やり直してください。スコア更新の進行中は削除できないため、更新が完了してから送信してください。
:::

ゲームアカウントを 1 つだけ外して他のデータを残したい場合は、連携ページでそのアカウントを個別に連携解除してください。詳しくは[連携済みアカウントの管理](#bind)を参照してください。

**例：**

| コマンド | 説明 |
|---------|------|
| `/アカウント削除` | 削除内容を確認し、削除リクエストを開始 |
| `/アカウント削除 確認` | 確認して削除を実行（5 分以内有効） |

## カード選択 {#aime}

現在のサーバーで関連付けられたゲームアカウントを切り替えます。異なる方法で更新したデータ（中国版の NET と MAID、LXNS、カスタムデータソースなど）はそれぞれ別のアカウントになり、互いに上書きされません。照会には現在選択中のアカウントが使われます。

**コマンド：** `/カード選択 [番号]`

**エイリアス：** `アカウント切替`、`aime`

**説明：**

- `/カード選択`：現在のサーバーのアカウントを一覧表示し、現在のアカウント、Rating、更新方法、最終更新日時を表示します。
- `/カード選択 <番号>`：指定したアカウントに切り替えます。
- 日本版で SEGA ID を連携している場合、その SEGA ID のうちまだ更新していない Aime カードも一覧に表示されます。このカードを選ぶと、次回の `/データ更新` でそのカードが更新され、完了後に自動でそのカードへ切り替わります。

ある方法でスコアを更新すると、その方法に対応するアカウントに自動で切り替わります。連携ページのアカウント一覧から選んで切り替えることもできます。

**例：**

| コマンド | 説明 |
|---------|------|
| `/カード選択` | 現在のサーバーのアカウント一覧を表示 |
| `/カード選択 2` | 2 番目のアカウントに切り替え |

## ユーザー名設定

`#ユーザー名` で他のユーザーがあなたのデータを照会しやすくするユーザー名を設定します。

**コマンド：** `/ユーザー名設定 [ユーザー名|クリア]`

**例：**

| コマンド | 説明 |
|---------|------|
| `/ユーザー名設定 Sakura` | ユーザー名を Sakura に設定 |
| `/ユーザー名設定` | 現在のユーザー名を確認（未設定時は照会 ID を表示） |
| `/ユーザー名設定 クリア` | ユーザー名をクリア |

**ユーザー名のルール：** 漢字・ひらがな・カタカナ・英数字が使えます（数字のみは不可）。10 文字以内です。半角カタカナや全角英数字は自動で変換されます。既存のユーザー名と見分けにくい名前は設定できません。

**照会 ID：**

すべてのユーザーにはシステムが自動付与する**照会 ID**（`#mc` 始まりの短い ID）があります。ユーザー名を設定していなくても、この ID で他のユーザーから照会してもらえます。ユーザー名を設定後は `#ユーザー名` と照会 ID のどちらでも使えます。

::: warning 注意
ユーザー名をクエリパラメーターとして使用する際は、必ず `#` を先頭に付けてください。

例：`/b50 #Sakura`（`/b50 Sakura` ではありません）
:::

::: tip 審査について
ユーザー名は設定後に審査が行われます：

- **審査中**：`#ユーザー名` で照会は可能ですが、表示時にユーザー名が一部マスクされます
- **審査通過**：ユーザー名が完全表示されます
- **審査不合格**：ユーザー名は自動削除されます。再設定が必要です

ユーザー名は **3 日間に 1 回** しか変更できないため、慎重に設定してください。
:::

## プライバシー設定 {#privacy}

他のユーザーがあなたのゲームデータを照会できるかどうかを制御します。

**コマンド：** `/公開設定 <アクション> [対象]`

**アクション：**

| アクション | 説明 |
|-----------|------|
| `状態` | 現在のプライバシー設定を確認 |
| `オン` | 指定対象の照会を許可 |
| `オフ` | 指定対象の照会を拒否 |
| `リセット` | すべての照会権限をデフォルト（全許可）に戻す。対象は不要 |

**対象：**

| 対象 | 説明 |
|------|------|
| `閲覧` | マスタースイッチ — すべての照会権限を制御 |
| `b50閲覧` | Best 50 などの各種 50 系照会、PK・レート上げの照会 |
| `スコア閲覧` | スコア（info）・プレイ履歴・レート推移の照会 |
| `進捗閲覧` | コンプリート表・進捗・ジャンル進捗・スコアリストの照会 |

::: tip
`閲覧`（マスタースイッチ）を無効にすると、他のユーザーはあなたのデータを一切照会できなくなります。個別設定より優先されます。ランキングは公開設定の対象外です。
:::

**例：**

| コマンド | 説明 |
|---------|------|
| `/公開設定 状態` | 現在のプライバシー状況を確認 |
| `/公開設定 オフ 閲覧` | 他ユーザーによるすべての照会を拒否 |
| `/公開設定 オフ スコア閲覧` | スコア照会のみを拒否 |
| `/公開設定 オン b50閲覧` | Best 50 照会を再び許可 |
| `/公開設定 リセット` | すべての照会権限をデフォルトにリセット |

## フレンド管理 {#friends}

McMai のフレンドリストを管理します（PK 機能で使用）。

**コマンド：** `/フレンド [アクション] [パラメーター]`

**アクション：**

| アクション | 説明 | パラメーター |
|-----------|------|------------|
| `リスト` | フレンドリストを表示 | — |
| `追加` | フレンドを追加 | `#ユーザー名` または `#照会ID`。スロット番号（1～3）を続けると、そのスロットを上書き |
| `削除` | フレンドを削除 | スロット番号（1～3） |

**例：**

| コマンド | 説明 |
|---------|------|
| `/フレンド リスト` | フレンドリストを表示 |
| `/フレンド 追加 #Sakura` | Sakura というフレンドを追加 |
| `/フレンド 追加 #Sakura 1` | スロット 1 を上書きして Sakura を追加 |
| `/フレンド 削除 1` | スロット 1 のフレンドを削除 |
