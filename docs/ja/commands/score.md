# スコア照会

## 個人楽曲データ

指定した楽曲の個人プレイ詳細（達成率・DX スコア・FC/FS 状態など）を照会します。

**コマンド：** `/info <曲 ID または曲名>`

| パラメーター | 説明 |
|------------|------|
| 曲 ID または曲名 | 数字 ID または曲名/別名 |

`#ユーザー名` を付けると他のプレイヤーのデータを照会できます。

**例：**

| コマンド |
|---------|
| `/info 11451` |
| `/info 潘多拉` |
| `/info 11451 #Sakura` |

## スコアライン許容値

指定した難易度における各ノーツ種別の減点値、各 DX 星レベルに必要な DX スコアの許容範囲、および各ランクの TAP 失敗許容数を照会します。

**コマンド：** `/ボーダー <曲 ID> [難易度]`

| パラメーター | 説明 | デフォルト |
|------------|------|----------|
| 曲 ID | 数字 ID | — |
| 難易度 | `緑`、`黄`、`赤`、`むらさき`、`白` | むらさき（Master） |

**例：**

| コマンド |
|---------|
| `/ボーダー 11451` |
| `/ボーダー 11820 白` |

::: tip 画像に含まれる内容
- **DX 星レベル**：各 DX 星レベルに到達するために必要な DX スコアの許容範囲。
- **ランク許容**：理論値 101% を基準に、各ランク（SSS+ / SSS / SS+ / SS / S+ / S）に到達するために全体を通して許容できる TAP Great / TAP Good / TAP Miss 単一失敗の最大個数（3 段階は排他）。
:::

## リザルト解析（識分）

リザルト画像を送ると、達成率とノーツ判定内訳を認識し、**BREAK の内訳**（絶（Just）/ 50 落ち / 100 落ち など）とノーツ別の達成率失点を逆算します。

**コマンド：** `/readscore`

**使い方：**

- コマンドと**一緒に**リザルト画像を添付する；または
- リザルト画像を含むメッセージに**返信**し、Bot をメンションしてコマンドを送信する。

**結果画像に含まれる内容：**

- 一致した楽曲・難易度・DX 星レベル・コンボランク（FC / FC+ / AP / AP+）
- 判定内訳 & 失点表：各セルに「個数／合計失点／1 個あたりの失点」を表示
- 逆算された BREAK の内訳。数学的に等価な解が複数ある場合はすべて表示

### 手動修正モード

画像の圧縮が強く一部の数字が誤認識された場合は、画像なしでパラメーターを直接指定して正しい数値を渡せます。

**コマンド：** `/readscore id=<曲 ID> ach=<達成率> tap=<CP/P/GR/GD/MS> hold=... slide=... touch=... break=...`

| パラメーター | 説明 | 必須 |
|------------|------|------|
| `id` | 数字の曲 ID | `id` かノーツ内訳のいずれか一方は必須 |
| `ach` | 達成率（0～101）、例：`100.8623` | 必須 |
| `tap` / `hold` / `slide` / `break` | 種別ごとの 5 段階判定数。`CP/P/GR/GD/MS` の順に `/` 区切り | 必須 |
| `touch` | 同上。TOUCH がない譜面では省略可（すべて 0 として扱う） | 任意 |

パラメーター名は常に英語です（`ach` は `acc` でも可）。順序は問いません。

**例：**

```
/readscore id=834 ach=100.8623 tap=380/0/0/0/0 hold=52/0/0/0/0 slide=90/0/0/0/0 touch=0/0/0/0/0 break=47/0/1/0/0
```

::: tip 認識精度を上げるには
- できるだけ**元画像（オリジナル）**を送信し、ゲーム画面**上部のノーツ内訳**が鮮明に写るようにしてください。
- 認識に失敗した場合、Bot は読み取れた数値入りのコマンドを返信します。コピーして誤った数字を直し、送り直してください。Discord では「✏️ 修正パラメーター」ボタンから入力できます。
:::

::: warning 制限
- 宴譜（UTAGE）のスコア逆算には未対応です。
- 同じノーツ内訳が複数の楽曲に一致する場合は、`id=` で譜面を指定してください。
:::

## 譜面統計

指定した楽曲の各難易度における AP 率・FC 率・プレイ率などの統計を照会します。

**コマンド：** `/譜面統計 <曲 ID または曲名> [サーバー]`

| パラメーター | 説明 | 選択肢 |
|------------|------|--------|
| 曲 ID または曲名 | 数字 ID または曲名/別名 | — |
| サーバー | サーバーで絞り込み（任意） | `cn`、`jp`、`intl` |

**例：**

| コマンド |
|---------|
| `/譜面統計 11451` |
| `/譜面統計 潘多拉` |
| `/譜面統計 11451 jp` |
| `/譜面統計 11451 cn` |
