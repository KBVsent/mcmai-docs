# 進捗照会

## レベル進捗 / プレート進捗

指定したレベルまたはバージョンプレートの達成状況やスコア統計を照会します（絞り込み・ページング対応）。

**コマンド：** `/進捗 <レベルまたはプレート> [目標] [絞り込み] [ページ]`

モードは 3 つあります。レベルと目標を指定すると**レベル進捗**、レベルのみだと**レベル統計**、プレート文字と称号レベルを指定すると**プレート進捗**です。

### レベルモード

| パラメーター | 説明 | 例 |
|------------|------|----|
| レベル | `1`〜`15`（`+` 付き可） | `13+` |
| 目標 | グレード名、FC / 同期目標、または DX スター | `SSS`、`fc`、`5star` |
| 完了/未完了/未開始 | 任意、完了状態で絞り込み | `完了`、`未完了`、`未開始` |
| ページ | 任意、デフォルト 1 ページ目 | `2` |

**グレード基準：**

| グレード | 達成率 |
|---------|--------|
| `S` | ≥ 97.0000% |
| `S+` | ≥ 98.0000% |
| `SS` | ≥ 99.0000% |
| `SS+` | ≥ 99.5000% |
| `SSS` | ≥ 100.0000% |
| `SSS+` | = 101.0000% |

**同期/FC キーワード：** `fc`、`fc+`、`ap`、`ap+`、`fs`、`fs+`、`fdx`、`fdx+`

**DX 星レベル目標：** `1star` ～ `7star`（例：`5star` は DX 星レベル ≥ 5；`7star` は理論 DXScore 100%）

**例：**

| コマンド |
|---------|
| `/進捗 13+ SSS` |
| `/進捗 14 fc` |
| `/進捗 14 5star` |
| `/進捗 13+ SS 完了` |
| `/進捗 14 ap 未完了 2` |

::: tip 画像に含まれる内容
達成率リングと、難易度 × 定数ごとの達成率マトリクス。未完了の譜面には目標までの差が表示されます。
:::

### レベル統計モード {#level-stats}

目標を省略すると、そのレベルのスコア統計を表示します。

**形式：** `/進捗 <レベル> [プレイ済み/未プレイ] [ページ]`

統計には、プレイ率と平均達成率、評価 / コンボ / 同期 / DX スターの分布（未プレイの譜面も含む）、難易度 × 定数ごとのプレイ数と平均達成率が含まれます。`プレイ済み` または `未プレイ` を付けると、該当する譜面をページ送りで確認できます。

**例：**

| コマンド | 説明 |
|---------|------|
| `/進捗 13+` | 13+ のスコア統計 |
| `/進捗 13+ プレイ済み` | 13+ のプレイ済み譜面 |
| `/進捗 13+ 未プレイ 2` | 13+ の未プレイ譜面、2 ページ目 |

### プレートモード

バージョンプレートのコンプリート進捗を照会します（例：`circle sss`、`prism ap`）。

**形式：** `/進捗 <プレート> <プレートレベル>`

| プレートレベル | 要件 |
|-------------|------|
| `fc` | 全楽曲 FC |
| `sss` | 全楽曲 SSS |
| `ap` | 全楽曲 AP |
| `fdx` | 全楽曲 FDX |

プレート文字（`丸`、`鏡` など）または英語バージョン名（`circle`、`prism` など）が使用できます。

**例：**

| コマンド |
|---------|
| `/進捗 circle sss` |
| `/進捗 plus fc` |
| `/進捗 prism ap 2` |

::: tip
英語版バージョン名エイリアスとプレートレベルを指定できます。例：`/進捗 circle sss`。
:::

## ジャンル進捗

楽曲ジャンル（アニメ・東方 Project など）別に進捗やスコア統計を照会します。

**コマンド：** `/ジャンル進捗 <ジャンル> [目標] [絞り込み] [ページ]`

| パラメーター | 説明 | 例 |
|------------|------|----|
| ジャンル | 楽曲カテゴリ名 | `アニメ`、`東方`、`オリジナル`、`ボカロ`、`ゲーム`、`オンゲキ`、`宴` |
| 目標 | 任意。グレード名または FC / 同期目標。省略するとそのジャンルのスコア統計を表示（[レベル統計モード](#level-stats)と同じ） | `SSS`、`fc`、`ap` |
| 絞り込み | 任意。目標ありは `完了`、`未完了`、`未開始`、目標なしは `プレイ済み`、`未プレイ` | `完了` |
| ページ | 任意、デフォルト 1 ページ目 | `2` |

**例：**

| コマンド |
|---------|
| `/ジャンル進捗 アニメ SSS` |
| `/ジャンル進捗 東方 SS 2` |
| `/ジャンル進捗 オリジナル fc 完了 2` |
| `/ジャンル進捗 アニメ` |
| `/ジャンル進捗 宴 プレイ済み` |

## スコアリスト

指定したレベル/定数における全楽曲のスコアリストを、多次元フィルターとソートで照会します。

**コマンド：** `/スコアリスト [レベルまたは定数] [フィルター...] [ソート] [ページ]`

**フィルター（複数組み合わせ可）：**

| 種別 | 値 |
|------|-----|
| Combo | `ap`、`ap+` / `app`、`fc`、`fc+` / `fcp`、`寸`（惜しくもコンボ切れ） |
| Sync | `fs`、`fs+` / `fsp`、`fdx`、`fdx+` / `fdxp` |
| グレード | `sss+`、`sss`、`ss+`、`ss`、`s+`、`s`、`a`、`aa`、`aaa`、`b`、`bb`、`bbb` など |
| 譜面タイプ | `dx`、`sd` |
| 新旧バージョン | `new`（新バージョン）、`old`（旧バージョン） |
| DX 星レベル | `1star` ～ `7star`（`7star` = 理論 DXScore 100%） |
| ゲームバージョン | 称号漢字（`双`、`鏡`、`丸` など）またはバージョンの英語エイリアス（`buddies`、`prism` など。無印でらっくすは `deluxe`）。PLUS バージョンは末尾に `+` を付けて `buddies+` のように指定 |

**演算子（Combo / Sync / グレードのみ）：**

| 書き方 | 意味 |
|------|------|
| 記号なし（`fc`、`sss` など） | Combo / Sync はそれ以上を含む（`fc` は FC+・AP なども含む）。グレードは完全一致（`sss` は SSS のみで SSS+ は含まない） |
| `=`（`=fc` など） | 完全一致。例：`=fc` は FC だけ（FC+ 未満）の譜面のみ表示 |
| `>=` または `以上`（`>=s`、`s以上` など） | そのランク以上。例：`>=s` は S 以上の譜面を表示 |

引数に誤りがある場合は、どの引数が認識できなかったかと、入力しようとした可能性のある書き方が表示されます。結果画像には照会条件が表示され、絞り込んだスコアの評価・コンボ・同期・DX スターの分布も集計されます。

**ソート：** `X順`（デフォルトは降順）、または `X順+`（昇順）/ `X順-`（降順）

ソート可能フィールド：`ra`（Rating 貢献）、`達成度` / `acc`、`dx`（DX スコア）、`定数` / `ds`

**例：**

| コマンド | 説明 |
|---------|------|
| `/スコアリスト 13+` | 全 13+ 楽曲のスコア一覧 |
| `/スコアリスト 14 fc` | FC 以上で絞り込み |
| `/スコアリスト 14 =fc` | FC のみ（FC+ 未満）を表示 |
| `/スコアリスト 14 ap 2` | AP 以上で絞り込み、2 ページ目 |
| `/スコアリスト 14 dx sss` | DX 譜面 かつ SSS のみ（SSS+ は含まない） |
| `/スコアリスト 14 dx >=sss` | DX 譜面 かつ SSS 以上 |
| `/スコアリスト s以上` | S 以上のスコアをすべて表示 |
| `/スコアリスト 14 ra順-` | Rating 貢献の降順でソート |
| `/スコアリスト 14 1star` | DX 星レベル 1 で絞り込み |
| `/スコアリスト buddies` | BUDDiES バージョンの楽曲で絞り込み |
| `/スコアリスト buddies+` | BUDDiES PLUS バージョンの楽曲で絞り込み |
