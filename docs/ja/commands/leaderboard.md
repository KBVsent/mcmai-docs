# ランキング

## 全体楽曲ランキング

全プレイヤーを対象とした楽曲の達成率ランキングを照会します。

**コマンド：** `/ランキング <曲 ID または曲名> [難易度] [サーバー]`

**パラメーター：**

| パラメーター | 説明 | デフォルト |
|------------|------|----------|
| 曲 ID または曲名 | 数字 ID または曲名/別名 | — |
| 難易度 | `緑`、`黄`、`赤`、`むらさき`、`白` | むらさき（Master） |
| サーバー | `cn`、`jp`、`intl` | 全サーバー |

**例：**

| コマンド |
|---------|
| `/ランキング 11451` |
| `/ランキング 潘多拉` |
| `/ランキング 11451 むらさき` |
| `/ランキング 11451 白 jp` |
| `/ランキング 11451 むらさき cn` |

::: tip 画像に含まれる内容
その譜面のスコア分布（全サーバーまたはグループ内）。
:::

## グループ内楽曲ランキング {#group-song-rank}

現在のグループ内プレイヤーの達成率ランキングを照会します。

**コマンド：** `/グルラン <曲 ID または曲名> [難易度] [サーバー] [ページ]`

パラメーターは `/ランキング` と同じです。末尾にページ番号を付けると、下位の順位を表示できます。サーバーには `all` も指定でき、中国版・日本版・インターナショナル版に加えて、[LXNS](/ja/commands/account#lxns)や[カスタムデータソース](/ja/guide/custom-data-source)などの外部データソースのスコアもあわせて表示します。同じプレイヤーに中国版・日本版・インターナショナル版のスコアがある場合はそちらを優先し、ない場合のみ外部データソースのスコアを使い、ランキング上にデータソースを表示します。

**例：**

| コマンド |
|---------|
| `/グルラン 11451` |
| `/グルラン 潘多拉 むらさき` |
| `/グルラン 11451 白 cn` |
| `/グルラン 11451 all` |
| `/グルラン 11451 2` |

::: tip ページ送り
`/グルラン` と `/グループレート` は 1 ページに 10 人ずつ表示され、画像内に次のページのコマンドが表示されます。ボタンに対応したプラットフォームでは、ボタンを押してページを切り替えられます。自分の順位と前後のプレイヤーは 1 ページ目にのみ表示されます。
:::

## グループ内 Rating ランキング

現在のグループ内プレイヤーの Rating ランキングを照会します。

**コマンド：** `/グループレート [サーバー] [ページ]`

| パラメーター | 説明 | 選択肢 |
|------------|------|--------|
| サーバー | サーバーで絞り込み（任意）。`all` は外部データソースのスコアもあわせて集計します（ルールは[グループ内楽曲ランキング](#group-song-rank)と同じ） | `cn`、`jp`、`intl`（または `中国版`、`日本版`、`インターナショナル版`）、`all` |
| ページ | 1 ページ 10 人（任意） | `2` |

**例：**

| コマンド |
|---------|
| `/グループレート` |
| `/グループレート jp` |
| `/グループレート 日本版` |
| `/グループレート all` |
| `/グループレート jp 2` |

::: tip 画像に含まれる内容
グループ全体の Rating 段位分布と、総人数・平均・最高・中央値などの概要データ。
:::

::: tip 新バージョンのレコードのみ対象
ランキングの各プレイヤーには、最後にレコードを更新した時刻が表示されます。所属サーバーで新バージョンが配信された後にまだ更新していないプレイヤーは、ランキング・段位分布・人数の集計から除外され、画像内に未更新の人数が表示されます。自分のレコードが古い場合は、レコードを更新すればランキングに掲載されます。
:::

## グループランキングに参加

グループ内でデータを更新するか、B50・B40・AP50・PC50 を照会すると、そのグループのランキングに自動で参加します。退出後に再び参加したいときや、照会せずに参加したいときにこのコマンドを使います。

**コマンド：** `/グルラン参加`

---

## グループランキングから退出

現在のグループのランキングから退出します。

**コマンド：** `/グルラン退出`

---

## グループランキング管理（オーナー / 管理者）

グループのオーナーまたは管理者は、メンバーをこのグループのランキングから除外したり、復元したりできます。

::: info QQ プラットフォームのみ
この機能は QQ プラットフォームのグループオーナー / 管理者のみ利用できます。
:::

**コマンド：** `/gban <#照会ID または #ユーザー名>`、`/gunban <#照会ID または #ユーザー名>`

**説明：** 対象メンバーは、グループランキングに表示されている `#` 付きの照会 ID またはユーザー名をそのまま入力してください。除外されたメンバーは自分では再参加できず、管理者が `/gunban` で復元する必要があります。

**例：**

| コマンド | 説明 |
|---------|------|
| `/gban #mc00000` | このメンバーをグループランキングから除外 |
| `/gban #Sakura` | 同上、ユーザー名を使用 |
| `/gunban #mc00000` | このメンバーのグループランキングを復元 |
