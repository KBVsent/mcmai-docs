# ランキング

## 全体楽曲ランキング

全プレイヤーを対象とした楽曲の達成率ランキングを照会します。

**コマンド：** `/ランキング <曲 ID または曲名> [難易度] [サーバー]`

**パラメーター：**

| パラメーター | 説明 | デフォルト |
|------------|------|----------|
| 曲 ID または曲名 | 数字 ID または曲名/別名 | — |
| 難易度 | `緑`、`黄`、`赤`、`むらさき`、`白` | むらさき（Master） |
| サーバー | `cn`、`jp`、`intl` | 全サーバー |

**例：**

| コマンド |
|---------|
| `/ランキング 11451` |
| `/ランキング 11451 むらさき` |
| `/ランキング 11451 白 jp` |
| `/ランキング 11451 むらさき cn` |

::: tip
`/ランキング` と `/グルラン` の画像には、その譜面の**スコア分布**（全サーバー・グループ内）が付帯するようになりました。
:::

---

## グループ内楽曲ランキング

現在のグループ内プレイヤーの達成率ランキングを照会します。

**コマンド：** `/グルラン <曲 ID または曲名> [難易度] [サーバー]`

パラメーターは `/ランキング` と同じです。

**例：**

| コマンド |
|---------|
| `/グルラン 11451` |
| `/グルラン 11451 白 cn` |

---

## グループ内 Rating ランキング

現在のグループ内プレイヤーの Rating ランキングを照会します。

**コマンド：** `/グループレート [サーバー]`

| パラメーター | 説明 | 選択肢 |
|------------|------|--------|
| サーバー | サーバーで絞り込み（任意） | `cn`、`jp`、`intl` |

**例：**

| コマンド |
|---------|
| `/グループレート` |
| `/グループレート jp` |

::: tip
グループ Rating ランキング画像には、グループ全体の Rating **段位分布**に加え、総人数・平均・最高・中央値などの概要データが付帯するようになりました。
:::

---

## グループランキングに参加

自分を現在のグループのランキングに追加します。参加後、データが `/グルラン` と `/グループレート` に反映されます。

**コマンド：** `/グルラン参加`

---

## グループランキングから退出

現在のグループのランキングから退出します。

**コマンド：** `/グルラン退出`

---

## グループランキング管理（オーナー / 管理者）

グループのオーナーまたは管理者は、メンバーをこのグループのランキングから除外したり、復元したりできます。

::: info QQ 公式グループのみ
この機能は QQ 公式プラットフォームのグループオーナー / 管理者のみ利用できます。
:::

**コマンド：** `/gban <#照会ID または #ユーザー名>`、`/gunban <#照会ID または #ユーザー名>`

**エイリアス：** gban = `踢出群榜` = `移出群榜`；gunban = `恢复群榜` = `移回群榜`

**説明：** 対象メンバーは、グループランキングに表示されている `#` 付きの照会 ID またはユーザー名をそのまま入力してください。除外されたメンバーは自分では再参加できず、管理者が `/gunban` で復元する必要があります。

**例：**

| コマンド | 説明 |
|---------|------|
| `/gban #mc00000` | このメンバーをグループランキングから除外 |
| `/gban #Sakura` | 同上、ユーザー名を使用 |
| `/gunban #mc00000` | このメンバーのグループランキングを復元 |
