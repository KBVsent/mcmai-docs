# maimai DX スコア照会ガイド

McMai は、maimai DX プレイヤー向けの無料スコア照会／分析 Bot です。QQ・LINE・Discord から、中国版（CN）・日本版（JP）・国際版（INTL）のプレイデータを更新・照会できます。

## 照会できる内容

| 目的 | McMai の機能 | 詳細 |
|------|--------------|------|
| 総合成績を確認 | レーティング上位譜面の成績画像を生成 | [ベストスコア分析](/ja/commands/b50) |
| 楽曲別の成績を確認 | 達成率、DX スコア、FC/FS 状態を表示 | [スコア照会](/ja/commands/score) |
| 楽曲・譜面を探す | 曲名、別名、作曲者、BPM、定数などで検索 | [楽曲検索](/ja/commands/search) |
| 達成状況を追跡 | レベル、カテゴリ、コンプリート状況を表示 | [進捗照会](/ja/commands/progress) |
| 他のプレイヤーと比較 | ランキングやフレンド比較を利用 | [ランキング](/ja/commands/leaderboard) |

## 対応サーバーと更新方法

| サーバー | データ更新方法 |
|----------|----------------|
| 中国版（CN） | 「舞萌｜中二」WeChat 公式アカウントのプレイヤー QR コードから取得した `SGWCMAID` を Bot に送信 |
| 日本版（JP） | `/連携` から連携ページを使用するか、パスワードを送信しないブックマークレット方式で更新 |
| 国際版（INTL） | `/連携` から連携ページを使用するか、パスワードを送信しないブックマークレット方式で更新 |

連携、ブックマークレット、サーバー切り替えの詳細は[アカウントとサーバー](/ja/commands/account)を参照してください。

## スコア照会を始める

1. QQ・LINE・Discord のいずれかで McMai を追加します。
2. プレイしている地域に合った方法でデータを更新します。
3. `/鯖変更` で CN・JP・INTL のいずれかを選択します。
4. `/b50` で上位成績を確認するか、`/info <楽曲IDまたは曲名>` で楽曲別の成績を照会します。

Bot をまだ追加していない場合は、[はじめに](/ja/guide/getting-started)をご覧ください。その他の機能やパラメーターは[コマンド一覧](/ja/commands/basic)で確認できます。

::: info プライバシーについて
日本版・国際版では、SEGA ID とパスワードを McMai に送信せず、ブックマークレットで成績を更新することもできます。
:::
