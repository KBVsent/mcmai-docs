中国版 NET のスコアは、連携ページの NET WeChat 認証から更新できます。初回はプロキシの設定と認証リンクの保存が必要です。認証は更新のたびに行います。

## 準備 {#prepare}

1. Bot に `/連携` を送り、返された連携リンクを開きます。
2. 中国版の NET WeChat 認証を選び、認証リンクを取得します。
3. ゲームアカウントに対応する WeChat アカウントで認証します。

認証リンクは、使用するアカウントの連携ページに表示されたものを使います。図解の画面表示言語は個別に選択できます。

## 1. プロキシの設定 {#proxy}

[iPhone / iPad](#ios) · [Android（Pixel）](#android) · [Windows 11](#windows) · [macOS](#macos) · [Clash](#clash)

WeChat 認証を行う端末にプロキシを設定します。スマートフォンでは、Wi-Fi の手動プロキシまたは Clash 設定に対応するクライアントのいずれかを使用します。既存のプロキシ設定は変更前に記録し、更新後に戻します。

::: info パソコン向け手順の範囲
Windows と macOS の図解はシステムプロキシの設定手順です。デスクトップ版 WeChat の認証全体は実機検証していません。スマートフォンの WeChat でリンクを開く場合は、スマートフォン側の設定が必要です。パソコンのプロキシ設定はスマートフォンには適用されません。
:::

### iPhone / iPad：Wi-Fi の手動プロキシ {#ios}

Wi-Fi に接続し、認証中のモバイル回線への切り替えを防ぐため、モバイルデータ通信と「Wi-Fi アシスト」を一時的にオフにします。「Wi-Fi アシスト」は通常「設定」→「モバイル通信」の下部にあります。

<CnNetIosGuide />

Wi-Fi プロキシが有効な間は、ほかの Web サイトが開けない場合があります。認証画面で引き継ぎ完了を確認した後、[プロキシをオフ](#finish)にして連携ページに戻ります。接続する Wi-Fi を変更した場合は、新しいネットワークにも設定が必要です。

### Android：Google Pixel {#android}

図解は Google Pixel の例です。Wi-Fi に接続し、モバイルデータ通信とネットワークの自動切り替えを一時的にオフにします。メニュー名や位置はメーカーによって異なります。

<CnNetProxyGuide platform="android" />

ネットワーク設定にプロキシの項目がない場合は、メーカーの説明を確認するか、対応する Clash クライアントを使用します。設定経路は [Google Pixel 公式ヘルプ](https://support.google.com/pixelphone/answer/9655181?hl=en)を参照してください。

### Windows 11：システムプロキシ {#windows}

「設定」→「ネットワークとインターネット」→「プロキシ」で手動プロキシを設定します。Windows 10 では画面の配置が異なる場合があります。

<CnNetProxyGuide platform="windows" />

設定経路は [Microsoft 公式ヘルプ](https://support.microsoft.com/en-us/windows/experience/connectivity-networking/use-a-proxy-server-in-windows)を参照してください。

### macOS：ネットワークプロキシ {#macos}

「システム設定」→「ネットワーク」で使用中のサービスを選び、「詳細」→「プロキシ」を開きます。図解は Wi-Fi の例です。旧版 macOS では設定経路が異なる場合があります。

<CnNetProxyGuide platform="macos" />

設定経路と各項目は [Apple 公式ヘルプ](https://support.apple.com/en-gb/guide/mac-help/mchlp2591/mac)を参照してください。

### Clash：設定のインポート {#clash}

1. 連携ページのプロキシ設定でインポートボタンを押します。クライアントが開かない場合は、Clash 設定 URL をコピーし、クライアントで URL からインポートします。
2. インポートした McMai 設定を選択し、プロキシを有効にします。必要なシステム権限はクライアントの案内に従って許可します。
3. 連携ページに戻り、プロキシの検出結果を確認します。

インポート後は設定の有効化が必要です。提供される設定では認証コールバックのみがプロキシを経由し、その他の通信は設定内のルールに従います。項目名はクライアントによって異なります。

## 2. WeChat 認証リンクの保存 {#wechat-entry}

1. 連携ページの WeChat 認証リンクをコピーします。
2. WeChat のファイル転送トーク（中国語表示では「文件传输助手」）に送り、次回の更新用にメッセージを残します。

::: warning 認証リンクの管理
リンクを持つ人は、自分の WeChat を使って対象の McMai アカウントにスコアを書き込めます。リンクの転送や公開画像への掲載は避けてください。流出した場合は連携ページでリセットし、新しいリンクを保存します。古いリンクは直ちに無効になります。
:::

## 3. WeChat での認証 {#authorize}

1. 設定済みプロキシを有効にします。Wi-Fi 方式は「手動」を選び、Clash 方式は McMai 設定を有効にします。
2. WeChat のファイル転送トークからリンクを開き、画面の案内に従って認証します。
3. 引き継ぎ完了の表示を待ちます。この時点で認証情報が更新サービスに渡り、続いてスコアの取得と処理が行われます。

## 4. プロキシの解除と結果確認 {#finish}

引き継ぎ完了後は、今回使用したプロキシをオフにするか、元の設定に戻します。

- **iPhone / iPad**：接続中の Wi-Fi の「プロキシを構成」で「オフ」を選んで保存します。
- **Android**：接続中の Wi-Fi のプロキシを「なし」にして保存します。
- **Windows / macOS**：今回有効にしたシステムプロキシをオフにします。
- **Clash**：プロキシを停止するか、元の設定に切り替えます。

一時的にオフにしたモバイルデータ通信や自動切り替えも元に戻し、連携ページ上部で更新状況を確認します。更新完了後は Bot に `/鯖変更 cn`、続いて `/b50` を送信するとスコアを確認できます。

## 次回の更新 {#next-time}

1. 設定済みプロキシを有効にします。
2. WeChat で保存済みリンクを開き、再認証します。
3. 引き継ぎ完了後にプロキシをオフにし、連携ページで結果を確認します。

リンクはリセットするまで繰り返し使用できます。リセット後は新しいリンクを保存します。Wi-Fi やプロキシの設定値を変更した場合は、該当するネットワーク設定も更新します。

## よくある問題 {#faq}

### プロキシが検出されない

サーバとポートの入力内容、設定の保存状態を確認します。Wi-Fi 方式では設定したネットワークに接続し、プロキシを迂回する可能性のあるモバイルデータ通信や自動切り替えをオフにします。Clash 方式では McMai 設定とプロキシ機能の両方が有効か確認します。

### Wi-Fi プロキシが有効な間に Web ページが開けない

このプロキシの用途は更新時の認証に限られるため、ほかのサイトが開けない場合があります。引き継ぎ完了後にプロキシをオフにし、連携ページを確認します。WeChat 認証も失敗する場合は、設定を確認してリンクを開き直します。

### 認証後も更新中と表示される

引き継ぎ後も NET データの取得と処理が続きます。更新の成否は連携ページの最終状態で確認します。失敗した場合は画面の案内に従って再認証します。

### MAID による更新

中国版では引き続き MAID も使用できます。詳細は[中国版 MAID による更新](/ja/commands/account#maid)を参照してください。

2 つの方法では取得できるデータが異なり、一部の機能は直近の更新方法に従います。NET による更新にはプレイ履歴が含まれ、[`/プレイ履歴`](/ja/commands/score#recent-plays)と[`/レート推移`](/ja/commands/score#rating-history)を利用できます。MAID による更新にはプレイ回数が含まれ、[PC50](/ja/commands/b50#pc50) を利用できます。
